## 2. Zones

- **header** : `TopBar` (56px, 05 §3.4 l. 659-668) — titre « Objectifs » (`md` 600, max 1 ligne) + **`back`** (icône 44px — `/goals` est une route poussée depuis le bloc 7 du Home (WDS 02.2 §2 entrée #1), **contrairement** à `/projects` qui n'en a pas (05 §4.3.1 l. 1436)); le `back` = retour natif, **pas** un switch de tab (02 §6.1). `Badge Offline` si sync down (ui-libraries S6 l. 184).
- **content** : liste verticale de **`Card flat`** (05 §4.3.4 l. 1647-1650 : un objectif par card ; interdiction `ListItem` — l'objectif est un **objet riche**, idem projets §4.3.1 l. 1438-1440 ; tri par priorité, WDS 02.2 §6 OQ-1 close B). Chaque `Card flat` :
  - `titre` de l'objectif (`md` 600, `text-primary` — règle §3.3 l. 498-503 : une Card **sans** titre = interdit)
  - `Badge` de **terme** (court / moyen / long, `JetBrains Mono` `xs` — 05 §4.3.4 l. 1649-1650)
  - `Badge` de **statut** (WDS 02.2 §6 : `active` / `atteinte` / `en retard` — « En retard — écart documenté » = `danger-surface`, **fixe** si l'écart existe, OQ-2 close A)
  - `ProgressBar` (05 §3.3 l. 554-571) — la progression de l'objectif, valeur en `JetBrains Mono` `xs` à droite (**pas** de compteur animé, §2.6 règle 1 l. 323-330)
- **CTA de création** : `FAB` (05 §4.3.4 l. 1684-1688 : « le FAB (liste) ouvre une `BottomSheet` de création d'objectif ») — mobile-only ; **desktop** = `Button` dans la `TopBar` (05 §4.3.4 l. 1689-1693, pattern §4.3.1 l. 1476-1478 « le FAB est un **mobile-only** pattern, doc §23.2 »).
- **footer** : `BottomNav` (5 items figés : Accueil / Tâches / Apprendre / Progression / Coach — 05 §3.4 l. 670-688 ; `/goals` n'est **pas** un tab, entrée par push/retour, WDS 02.2 §2 ; **conflit** WDS 02.2 §6 (5ᵉ tab = `/agent`) = OQ-4).
- **surfaces flottantes** : `FAB` ; `BottomSheet` de création d'objectif (05 §4.3.4 l. 1684-1688 : `TextField` titre + `Select` terme court/moyen/long) ; `Toast`/`Snackbar` (file max 1, 05 §3.5 l. 823-841). **Aucun** `Menu` de tri dans le SSoT (OQ-5).

## 8. Pagination

**Règle unique nommée** : la liste est une liste de `Card flat` (pas un `Table`).

- **Volume < 100 objectifs** (cas courant Horeb : 3-6 objectifs, WDS 02.2 §7) : **pas de pagination** — la liste se scrolle naturellement (05 §4.3.4 ne mentionne **jamais** de pagination).

## 10. Thèmes

Comportement des 3 couches sur `/goals` (05 §5 l. 2925-3307 ; overview §3 l. 27-54) :

- **Couche 1 — Style neutre** (Light `#FFFFFF` / Dark `#121212`) : fournit `surface`, `surface-alt`/`bg-subtle` (fond des `Card flat`), `text-primary/secondary`, `border`, `shadow` — les tokens **géométriques et sémantiques** de l'écran. Le Dark est **première classe** (`#121212` plain dark, pas `#000` — overview §2 l. 17-23 ; Horeb = session nocturne, WDS 02.2 frontmatter).
- **Couche 2 — Thème expressif** (10 thèmes vivants : Aurora par défaut + 9, 05 §5.4 l. 3010-3046) : fournit `accent.primary/secondary` — les tokens **couleur** de l'écran (le `FAB` « Nouveau objectif » = `primary`, la `ProgressBar` = `primary`, le `Badge de terme` = `primary-surface`). **Règle bloquante §5.1** (05 l. 2931-2959 ; overview §3 l. 39-43) : un thème **ne redéfinit JAMAIS** `success`/`warning`/`danger`/`info` — le `Badge danger-surface` « en retard / à resync » et le `Badge success-surface` « atteint » sont **thème-indépendants** (neutral layer).
- **Couche 3 — Presets** (Slate / Nocturne / High Contrast, 05 §5.5 l. 3153-3165) : **Nocturne = thème par défaut de Horeb** (OQ-16, WDS 02.2 frontmatter : « Thème par défaut : Nocturne ») — les `Card flat` restent lisibles (le preset est appliqué **au-dessus** du thème, pas à la place — 05 §5.8 resolve.ts) ; High Contrast = `7:1 contrast`, `56px targets`, `3px focus ring` (overview §3 l. 45-49 ; 05 §6.3 l. 3327-3335) — le `FAB` (56px) reste **identique**.
- **Local adaptation V1** = Focus Mode **uniquement** (OQ-15, 05 §5.2 l. 2961-2990) — `/goals` n'a **pas** de local adaptation (le Focus Mode **bloque** les autres surfaces, WDS 02.2 §5 : « pas de variante Focus »).
- **Résolution** : `valeur = theme_accent[token] ?? style_neutre[token] ?? défaut` (05 §5.3 l. 2992-3008) — changée par `resolveToken` + `<AuroraThemeProvider>` (JSON dans `packages/ui/src/themes/`, **jamais** de changement silencieux au foreground, 05 §5.8 l. 3235-3250).
