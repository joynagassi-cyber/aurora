## §1 Psychologie designer

| Dimension | Valeur |
|---|---|
| **Objectif utilisateur** (1 ligne) | Visualiser le plan d'ouverture du projet **sur le temps** — quand chaque tâche doit être exécutée (pas juste *quoi*, ADR §18.4 ; WDS 02.5 §3) — identifier le point de départ (première tâche du plan, ADR §18.5 ; WDS 02.5 OQ-2 close), puis actionner le CTA unique « Générer la fiche » vers `fiches-liste` (S-17). |
| **Contexte** | Mobile Android (Pixel 4a, OQ-11 WDS 02.5 §10), main libre, 23 h, thème Nocturne par défaut (WDS 02.5) ; entrée primaire = CTA « Visualiser sur timeline » de `projets-detail` (WDS 02.5 §2) ; réseau patchy probable → offline = état premier (AD-7, WDS 02.5 §10 : timeline stockée localement PowerSync mirror). |
| **Fréquence** | Point de visualisation de la chaîne 02 (WDS 02.5 §4 Business Goal) — consultation périodique du plan d'ouverture, pas un flux quotidien (le quotidien = `flashcards`/`qcm`). |
| **État émotionnel cible** | Clairté (le plan **sur le temps** est lisible, jalons non atteints marqués, dépendances visibles ; WDS 02.5 §3 Hope), confiance (le point de départ est **identifiable** — première tâche, WDS 02.5 §6), calme (pas de dashboard de widgets, WDS 02.5 §6 « pas un dashboard de widgets »), motivation (EmptyState positif : projet scindé → le plan devient actionnable en 1 geste, invariant AD-14). |
| **Erreur la plus probable** | Lire la liste comme un diagramme interactif (zoom/drag) — mitigation = **liste chronologique simple** (WDS 02.5 OQ-1 close option A 09/25 : le budget NFR OQ-11 — 30 fps, TTI < 1,5 s, JS < 300 Ko — ne permet pas un Gantt interactif) ; ou confondre cette vue (planification, `GanttRow` 05 §3.6.4) avec la vue narrative `Timeline` 05 §3.6.3 (événements passés) — les deux sont **distinctes** (05 §3.6.3 l.917 cite la distinction). |
| **Ce que l'écran RÉSOUT** | Le plan d'ouverture **mesuré sur le temps** : 1 liste de `GanttRow` (1 tâche = 1 ligne 44 px + barre 8 px proportionnelle sur axe de dates partagé, 05 §3.6.4 l.928–936) + 1 CTA d'action unique (invariant AD-14, WDS 02.5 §6/Q8 passo 5) ; lisible 100 % hors-ligne (miroir AD-7), la sortie reste actionnable (AD-1, master-feature-catalog l.22 : `productivity.projects` = offline-capable). |
