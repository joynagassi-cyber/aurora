## 10. Thèmes

Comportement des 3 couches sur le détail projet (05 §5 l. 2925-3306 ; overview §3 l. 27-54) :

- **Couche 1 — Style neutre** (Light `#FFFFFF` / Dark `#121212`, 05 §5.2 l. 2961-2970) : fournit `surface`/`surface-alt`/`bg-subtle` (fond du contenu des 5 tabs), `text-primary/secondary/muted`, `border`, `shadow` — les tokens **géométriques et sémantiques**. Dark = **première classe** (`#121212` plain dark, **pas** `#000` — overview §2 l. 17-23).
- **Couche 2 — Thème expressif** (10 thèmes vivants : Aurora par défaut, Lagoon, Boreal, Sakura, Vesper, Solara, Terra, Verdant, Citrus, Cosmos — 05 §5.4 l. 3010-3047) : fournit `accent.primary/secondary` — les tokens **couleur** (le `ProgressBar` = `primary`, la `Badge` du jalon `success` = `success-surface`, l'underline `Tabs` = `primary`). **Règle bloquante §5.1** (05 l. 2931-2959) : un thème **ne redéfinit JAMAIS** `success`/`warning`/`danger`/`info` — le `Badge danger` « à resync » (état `error`) et le `Callout info` « prochain jalon » sont **thème-indépendants** (neutral layer, §5.2 l. 2961-2970).
- **Couche 3 — Presets** (Slate / Nocturne / High Contrast, 05 §5.5 l. 3153-3165) : Nocturne = désaturation (le détail **reste identique** en structure, les teintes passent en métallique) ; High Contrast = `7:1 contrast`, `56px targets`, `3px focus ring` (overview §3 l. 45-49) — les `ListItem` (≥ 56 px) et le `Checkbox` (44 px → 56 px) **restent identiques** (ajustement, **pas** un nouveau composant). Les presets **ne redéfinissent jamais** `success`/`warning`/`danger`/`info` (§5.1, §5.5 — le `Badge danger` « à resync » reste `danger` dans **tout** preset).
- **Local adaptation V1** = Focus Mode **uniquement** (OQ-15 du workflow, 05 §5.2 l. 2961-2990 ; cf. `theme-adapter.tsx` ssootCode themeRefs) : le Focus Mode **atténue** les animations (`[data-focus-mode=true] .animate-pulse-skeleton = animation:none`, ssootCode forbidden) ; les toasts/snickers sont **différés** (jamais pendant un pomodoro, 05 §3.5 l. 835-837) ; le `ProgressBar` **continue** (le ring du Focus, §2.6 règle 3 : on ne coupe **pas** le timer, on coupe les toasts et les animations secondaires).
- **Résolution** : `valeur = theme_accent[token] ?? style_neutre[token] ?? défaut` (05 §5.3 l. 2992-3008) — changée par `resolveToken` + `<AuroraThemeProvider>` (JSON dans `packages/ui/src/themes/`, **jamais** de changement silencieux au foreground, 05 §5.8 l. 3235-3279) ; le thème = **skin only** (AD-17 : changer de thème change les **valeurs**, **jamais** le code — 05 §5 l. 2925-2930).
