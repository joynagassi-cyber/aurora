## §1 Psychologie designer

| Dimension | Valeur |
|---|---|
| **Objectif utilisateur** (1 ligne) | Capturer une charge universelle (notes du soir) en 1 geste (CTA « Capture this » fixe, 04.2 §2), la trier vers l'une des **3 destinations fixes** (tasks/learn/settings, 04.2 §6 — le chemin court du profil passe par `/learn` S-25) et voir la fiche `SourceRef` rattachée à la ressource (Boucles item 1, Screen Registry §A #22 §4.7.1) — **sans perte de saisie** (draft Tiptap persisté localement, AD-7). |
| **Contexte** | Mobile, fin de journée (22 h, forfait étudiant limité, 3G capricieuse — trigger-map §7 signal 15), thème Nocturne par défaut (OQ-16) ; l'écran s'ouvre au-dessus de la route courante (invariant S6.2 : scroll/filtres de la route parente préservés) ; offline = état premier (AD-7, PowerSync mirror local). |
| **Fréquence** | Quotidienne (la capture du soir est la boucle 1 de l'app — « capture CTA partout », Boucles item 1) ; chaque capture = **2 min** de saisie + triage (04.2 §10). |
| **État émotionnel cible** | Sécurité (la saisie ne se perd **jamais** — le back sauvegarde automatiquement, AD-7 / EXPERIENCE.md §Key Flows item 1) + contrôle (1 geste de capture, 1 geste de triage, 3 destinations fixes — jamais un 4ᵉ bouton libre, garde AD-14) + engagement (la fiche `SourceRef` rattachée = la preuve que l'entrée « vit » dans le flow, pas un bloc factuel opaque — ADR §13.4 ; trap « veille passive » 04.2 §6). |
| **Erreur la plus probable** | (a) Capture non triée laissée en veille — mitigation = le triage reste **actionnable offline** (la route `/learn` S-25 est locale, AD-7 ; la sync de la `SourceRef` est différée, 04.2 §3) ; (b) surcharge de destinations — mitigation = 3 destinations **fixes** (tasks/learn/settings, Surfaces §1 #2), jamais un dashboard de destinations (ADR §12, 04.2 §10) ; (c) perte de saisie réseau — mitigation = draft Tiptap persisté localement (AD-7, 04.2 §3). |
| **Ce que l'écran RÉSOUT** | Capture universelle + triage en 1 geste, 100 % actionnable offline (AD-1/AD-7) : composition 2 blocs fixes (éditeur Tiptap + rattachement `SourceRef` / triage 3 destinations) + CTA « Capture this » fixe haut (Boucles item 1) + CTA « Trier vers /learn » fixe bas (AD-14) + BottomNav 5 tabs (WDS 04.2 §6) ; `MathBlock` rendu local (AD-7), jamais une proposition libre de l'agent dans le chemin court (garde AD-14). |

## §4 États (matrice complète AD-13 / 05 §3.7)

### (a) 6 états S6 par élément async (ui-libraries §6 l.174–187)

- **loading** (ouverture de /inbox, mirror local AD-7) : Skeleton des 2 blocs (shape = blocs 1/2 finaux, ~300 ms max, AD-13) ; tokens = --aurora-skeleton ; texte exact = « Chargement de votre capture… » (court, local AD-7) ; CTA = « Capture this » + « Trier vers /learn » **indisponibles** (04.2 §7) ; **entrée** = fade 200ms easeOut (PAGE_TRANSITION, ssootCode motionRefs motion.tsx @aurora/ui) ; **sortie** = skeleton → blocs 1/2 crossfade 200ms (si > 300ms le contenu apparaît partiellement en dessous, pack 02 §7) ; **portée** = chargement du draft Tiptap local (AD-7) + rendu `MathBlock` (si formules) = 2 éléments §3 avec état S6 loading distinct.
- **empty** (première ouverture de /inbox, draft vide — 04.2 §7) : EmptyState « Aucune capture — capturez votre première note » + CTA « Capture this » (Boucles item 1, fixe) ; tokens = --aurora-bg-subtle + --aurora-text-secondary ; **entrée** = fade 200ms ; **sortie** = tap CTA → ouvre l'éditeur Tiptap (draft créé localement, AD-7) → retour au flux loading→default du §4a ; **portée** = `EmptyState` + CTA « Capture this » = 1 élément §3 (EmptyState avec CTA intégré, 05 §12 ; pack 02 §7 : jamais un bloc vide).
- **error** (mirror local corrompu / conflit de sync, 04.2 §7) : Callout warning « Données locales — resynchronisation en attente » (AD-7) — les 2 blocs (éditeur Tiptap + rattachement `SourceRef` / triage) passent en **read-only** depuis le mirror ; le CTA « Trier vers /learn » est **désactivé** (pas de triage sur des données potentiellement stale, 04.2 §7) ; tokens = --aurora-warning / --aurora-warning-surface (frozen, 05 §5.1) ; CTA = aucun (pas de retry in place, l'erreur reste affichée — AD-7 : « l'erreur reste affichée ») ; **entrée** = fade 200ms ; **sortie** = retour réseau OK → resync mirror → le CTA redevient actif (flux loading→default, 04.2 §7 « Tap quand réseau revenu (CTA redevient actif) ») ; **portée** = Callout warning (état error) + 2 blocs en read-only + CTA bas grisé = 3 éléments §3.
- **success** (triage effectué : l'entrée vit dans `/learn` S-25 avec sa fiche `SourceRef` rattachée — fin du passo 2 du scénario 04, 04.2 §7) : Toast success S6 l.183 (check vert, auto-dismiss 3s) ; tokens = --aurora-success (frozen, 05 §5.1) ; texte exact = OQ-08 §14 ; CTA = retour automatique à la route parente (S6.2) ou navigation vers `/learn` (selon OQ-07 §14) ; **entrée** = toast slide up 200ms easeOut (translateY, pas de layout, S5 l.169) ; **sortie** = auto-dismiss 3s (§3.5 l.823) ; **portée** = Toast de triage + CTA « Trier vers /learn » (passé en success state) = 2 éléments §3.
- **offline** (réseau coupé, capture chargée depuis le mirror local, 04.2 §7) : Badge offline en TopBar (S6 l.184, texte = OQ-04 §14) + Callout info fine « Les résultats de la capture seront synchronisés à la connexion » (04.2 §7 « bandeau fine « hors-ligne », AD-13 A5 ») — les 2 blocs (éditeur Tiptap + rattachement `SourceRef` / triage) restent **lisibles** (mirror local AD-7) ; `MathBlock` **rendu localement** (pas image serveur, AD-7, 04.2 §6/§10) ; le CTA « Trier vers /learn » **reste actionnable** (la route `/learn` S-25 est locale, AD-7 ; la synchronisation de la `SourceRef` est **différée**, 04.2 §7/§10) ; tokens = --aurora-info (frozen, 05 §5.1, Callout) + --aurora-warning (badge, S6 l.184) ; CTA = « Trier vers /learn » actif (pas de CTA serveur désactivé — le triage vers `/learn` est **local**) ; **entrée** = fade 200ms ; **sortie** = retour online → re-sync (la `SourceRef` est synchronisée alors, AD-7, WDS 04.2 OQ-2 close) ; **portée** = Offline badge TopBar + Callout info fine + CTA « Trier vers /learn » (actif, pas grisé) = 3 éléments §3 ; le draft **ne se perd jamais** (AD-7).
- **killed** (flux serveur mort : resync mirror / `SourceRef`, AD-13/G-M2, ui-libraries §6 l.185) : Skeleton + « Reconnexion… » (S6 l.185) sur le flux de resync **seulement** ; tokens = --aurora-skeleton (+ --aurora-danger pour le badge d'état) ; CTA = **aucun** (pas de retry, pas de navigation, ssootCode stateRefs ux-states.tsx) ; **entrée** = fade 200ms ; **sortie** = reconnexion OK → resync → loading/success ; le contenu **local** (draft Tiptap AD-7, `MathBlock` local) reste lisible **en dessous** et actionnable pendant le killed (pas de crash, pas de perte de contenu local, AD-7) ; **portée** = resync du mirror `SourceRef` (flux serveur uniquement, §4d) ; le draft local ne meurt **jamais** (AD-7).

### (b) États sémantiques §6.1 (ui-libraries l.189–202)

- **en-cours** (capture saisie en cours, draft Tiptap persisté localement à chaque geste, AD-7) : bloc 1 (éditeur Tiptap actif) + badge de rattachement `SourceRef` si déjà rattaché (mirror AD-7) ; tokens = --aurora-accent-primary (CTA « Capture this » actif) + --aurora-text-primary (corps édité) ; CTA = « Trier vers /learn » actif (pas de blocage, AD-7) ; source = 05 §3.3 + ui-libraries §6.1 l.197 (progression **mesurable** = ≠ S6 loading ; ici = la saisie qui persiste localement, pas une barre de progression).
