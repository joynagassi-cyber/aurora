## 2. Zones

- **header** : `TopBar` (56px, 05 §3.4 l. 659-668) — titre « Projets » (`md` 600, max 1 ligne) + **1 `IconButton`** (icône `more`, ouvre le `Menu` de tri : par date / par progression / par priorité — 05 §4.3.1 l. 1436-1437). **Pas de `back`** (route de première classe, écran non-pushed ; 02 §6.1). **Badge `Offline`** (si sync offline — ui-libraries S6 l. 184 : « Badge (top bar) »).
- **content** : liste verticale de **`Card flat`** (05 §3.3 l. 506 : « pas de shadow, fond `bg-subtle`, pour une Card **dans** une liste dense » ; interdiction `ListItem` — 05 §4.3.1 l. 1439). Chaque `Card flat` (05 §4.3.1 l. 1441-1445) :
  - `titre` du projet (`md` 600, `text-primary`)
  - `ProgressBar` (05 §3.3 l. 554-571) — le % de complétion du projet, affiché en `JetBrains Mono` `xs` à droite (règle donnée scientifique §2.6 l. 323-330 : valeur affichée, **pas** de compteur animé)
  - 2 `Badge` (05 §3.3 l. 531-539) : le **statut** du projet (ex. « en cours », `primary-surface`) + le **prochain jalon** en `JetBrains Mono` `xs` (ex. « Jalon : 12 oct. »)
  - un `KeyValueList` compact (05 §3.6.2 l. 895-907) : les tâches **totales/terminées** (ex. `5/12`, `xs` `JetBrains Mono`)
- **footer** : `BottomNav` (5 items figés : Accueil / Tâches / Apprendre / Progression / Coach — 05 §3.4 l. 670-691 ; `/projects` n'est **pas** un tab, c'est une route poussée/adjacente, 02 §6.1 ; le tab « Tâches » est le point d'entrée principal du module).
- **surfaces flottantes** : `FAB` (« Nouveau projet » — 05 §4.3.1 l. 1449 : le FAB **existe** sur cet écran, c'est un écran de création) ; `BottomSheet` de création (05 §4.3.1 l. 1452-1457 : `Select` d'objectif + `DateField` d'échéance + `TextField` de titre) ; `Menu` de tri (header) ; `Toast`/`Snackbar` (file max 1, 05 §3.5 l. 823-839).

## 4. États (6 S6 + sémantiques §6.1 + 404) — par élément async

**Règle d'état (05 §4.3.1 l. 1450-1464)** : la liste de projets est **local-first** (AD-7) — le `loading` = le store local, pas le cloud. L'écran **fonctionne** offline (lecture locale) ; seul le **scan de documents** (action cloud, pack 04 §3.2.3) est désactivé.

## 8. Pagination

**Règle unique nommée** : la liste de projets est une **liste de `Card flat`** (pas un `Table` AG Grid).

- **Volume < 100 projets** (cas courant, règle ui-libraries S8 l. 289-291) : **pas de pagination** — la liste se scrolle naturellement (le mobile-first est **une liste**, 05 §12 « simple en surface »).
- **Volume 100-500 projets** (OQ-1) : **AG Grid Community virtualisé** (ui-libraries S1 l. 20, S5 l. 167 : `rowBuffer: 10`, `maxVisibleRows: 30`, 60 fps Pixel 4a) — le mode `Card` est remplacé par un `DataTable` (AG Grid) **uniquement** si le volume dépasse 100 ; en dessous, la liste de `Card` scrolle.
- **Volume > 500** (OQ-1) : **Virtuoso** (`react-virtuoso`, ui-libraries S1 l. 63 : fallback OQ-09) pour la virtualisation de la liste de `Card`.
- **La règle de tri** (date / progression / priorité, 05 §4.3.1 l. 1436-1437) est **persistée** par écran (store UI pack 02 §3.2) — le retour sur `/projects` retrouve le tri d'avant (règle de non-surprise).

**Interdiction** : `shadcn Pagination` (ui-libraries S1 l. 37) est pour les **listes paginées** (`Table`), pas pour la liste de `Card` de projets (05 §4.3.1 ne mentionne **jamais** de pagination — c'est une liste scrolleuse, pas une paged list).

## 10. Thèmes

Comportement des 3 couches sur `/projects` (05 §5 l. 2925-3307 ; overview §3 l. 27-54) :

Le Dark est **première classe** (`#0A0E1A` blue-tinted near-black, pas `#000` pour éviter le banding OLED — overview §2 l. 17-23).
- **Couche 2 — Thème expressif** (10 thèmes vivants : Aurora par défaut, Lagoon, Boreal, Sakura, Vesper, Solara, Terra, Verdant, Citrus, Cosmos — 05 §5.4 l. 3010-3046) : fournit `accent.primary/secondary` — les tokens **couleur** de l'écran (le `FAB` « Nouveau projet » = `primary`, la `ProgressBar` = `primary`, les `Badge` statut = `primary-surface`). **Règle bloquante §5.1** (05 l. 2931-2959 ; overview §3 l. 39-43) : un thème **ne redéfinit JAMAIS** `success`/`warning`/`danger`/`info` — le `Badge danger` « à resync » (état `error`) et le `Badge info` `Offline` (TopBar) sont **thème-indépendants** (neutral layer).
- **Couche 3 — Presets** (Slate / Nocturne / High Contrast, 05 §5.5 l. 3153-3165) : High Contrast = `7:1 contrast`, `56px targets`, `3px focus ring` (overview §3 l. 45-49 ; 05 §6.3 l. 3327-3335) — le `FAB` (56px) reste **identique** (56px = déjà le target High Contrast, pas de changement) ; les `Card flat` passent en `56px tap target` (ajustement, pas de nouveau composant — 05 §6.3 l. 3330-3331).
- **Local adaptation V1** = Focus Mode **uniquement** (OQ-15, 05 §5.2 l. 2961-2990 ; overview §3 l. 34-38) — `/projects` n'a **pas** de local adaptation (le Focus Mode ne s'applique pas sur cet écran ; la V1 est limitée à Focus, OQ-15).
- **Résolution** : `valeur = theme_accent[token] ?? style_neutre[token] ?? défaut` (05 §5.3 l. 2992-3008) — changée par `resolveToken` + `<AuroraThemeProvider>` (JSON dans `packages/ui/src/themes/`, **jamais** de changement silencieux au foreground, 05 §5.8 l. 3235-3250).
