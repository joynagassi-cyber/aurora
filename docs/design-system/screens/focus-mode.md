# Écran : focus-mode — Focus mode (concentration)

> Module Productivité · Route `/focus` (router.tsx l.88, inventaire #23) · SSoT 05 §4.4.2 l.2044-2224 + 05 §3.6.9 l.1058-1106 + docs/focus-mode/spec.md (OQ-17 DPC v1.8) · Statut : détaillé

## §1 Psychologie designer

| Dimension | Valeur |
|---|---|
| **Objectif utilisateur** (1 ligne) | Se concentrer — le Focus est une **action** (AD-14 : « Accès Focus » = un `Button`, pas une Card ; 05 §4.4.2 l.2045-2050), pas une donnée à consulter. |
| **Contexte** | Mobile ; l'écran **est** le focus — chrome retiré (pas de TopBar, BottomNav masqué, 05 §4.4.2 l.2051-2086, anti-distraction) ; offline-capable (tout est local AD-7, 05 §4.4.2 l.2149-2167 : timer, tâches associées, réduction des notifications locales). |
| **Fréquence** | Sessions courtes à moyennes : Pomodoro 25 min (défaut, 05 §3.6.9 l.1070-1071) ou temps libre 5-90 min (`Slider`, 05 §3.2 l.472-473 ; pack 04 §4). |
| **État émotionnel cible** | Immersion, calme : le Focus « enlève » la navigation — l'utilisateur est **dedans**, pas « dessus » (05 §4.4.2 l.2078-2086) ; direction « Technical Calm » : un écran qui respire concentre (05 §1 l.64-69). |
| **Erreur la plus probable** | Attendre un **blocage** des applications (n'existe pas sur Android consumer, pack 04 §4.1 l.287-298) → l'UI affiche la capacité **réelle** (réduction, pas blocage, pack 04 §4.2 l.345-347 ; v1.8 DPC = détection `isBlockingAvailable()`, docs/focus-mode/spec.md §2 l.69-72, OQ-17). |
| **Ce que l'écran RÉSOUT** | `FocusTimer` (ring 160px + temps restant `3xl` `JetBrains Mono` + label tâche `sm` `text-secondary`, 05 §4.4.2 l.2056-2061, §3.6.9 l.1059-1065) + `SegmentedControl` (Pomodoro/Temps libre, 05 §3.4 l.711-718) + `Slider` (5-90 min si temps libre, 05 §3.2 l.471-478) + `KeyValueList` (tâches associées, `FocusSession` AD-15 porte `taskIds`, 05 §4.4.2 l.2069-2076) + `Callout info` (réduction des notifications, l.2087-2100) + `IconButton` « Terminer la session » (`ghost`, **pas** `destructive`, l.2108-2114) + `Button primary` « Démarrer » (seul CTA, l.2115-2117, AD-14). |

## §2 Zones (cartographie de l'écran)

- **Callout info (seul chrome, en haut)** : `Callout info` « Les notifications sont réduites pour cette session » — affichage de la capacité **réelle** du `FocusController` (pack 04 §4.2 l.345-347 : « l'UI affiche la capacité réelle ») : réduction, **pas** blocage qui n'existe pas sur Android consumer (pack 04 §4.1 l.293) ; `offline` = la réduction se limite aux notifications **locales** (`LocalNotificationAdapter`, pack 04 §3.2.5) si réseau indisponible pour OneSignal (05 §4.4.2 l.2155-2167) ; échec de mise en place = `Callout warning` à la place (l.2188-2198 : « un échec de réduction **doit** être signalé, pas caché »).
- **Zone timer central** : `FocusTimer` (05 §3.6.9) — `ProgressRing` mode « temps restant » (05 §3.3 l.572-588), diamètre **160px** (05 §4.4.2 l.2057-2058), temps restant au centre en `3xl` `JetBrains Mono` (l.1063-1064 : le seul endroit où le DS autorise `3xl` sur mobile), label de la tâche focusée en `sm` `text-secondary` sous le ring (l.2059-2061).
- **Zone mode de session** : `SegmentedControl` « Pomodoro | Temps libre » (2 segments, 05 §3.4 l.711-718) + `Slider` 5-90 min **uniquement** en mode « temps libre » (05 §4.4.2 l.2067-2068 ; Pomodoro = 25 min par défaut, break 5 min, l.1070-1071) + valeur courante affichée `JetBrains Mono` `xs` à droite du track (05 §3.2 l.475-476).
- **Zone tâches associées** : `KeyValueList` compact (05 §3.6.2 l.895-907) — tâches associées à la session (`FocusSession` AD-15 porte `taskIds`, 05 §4.4.2 l.2071-2076 ; shape = `taskRefs: string[]`, docs/focus-mode/spec.md §15 l.294) ; `empty` = « Aucune tâche associée » (l.2128-2144 : le Focus **fonctionne quand même** — la concentration n'est **pas** conditionnée par une tâche, docs/focus-mode/spec.md §15 l.353 : « A focus session MAY target zero tasks »).
- **Footer actions** : `IconButton` « Terminer la session » (`ghost`, **pas** `destructive` — terminer le focus n'est **pas** destructif, le timer **enregistre** le bilan, 05 §4.4.2 l.2108-2114) + `Button primary` « Démarrer » (**le seul CTA de l'écran**, AD-14 l.2115-2117).
- **Surface flottante** : `BottomSheet` de **bilan** (le `FocusSessionBilan`, 05 §4.4.2 l.2169-2188) — durée réelle, interruptions, score de concentration ; rendu = `ChartSpec focusBilan` (barre horizontale `planned vs actual` + `StatTile score` + `StatTile interruptions`, 05 §3.6.9 l.1089-1096) consommé par `DataVisualizationRenderer` G2 (pack 02 §5.3 l.330-334) ; CTA « Revenir au Home » (le bilan **précède** le retour, l.2181-2188).
- **BottomNav masqué** : le Focus **enlève** la navigation (05 §4.4.2 l.2078-2081) — le retour au `BottomNav` par le **back Android** ou l'`IconButton` « Terminer la session » en bas, **pas** par le nav (l.2082-2086).
- **Zones états** : `Callout` (info/warning/danger) / `Skeleton` (bilan) selon les états S6 (ui-libraries §6 l.174-187) + états sémantiques screen-level (ui-libraries §6.1 l.189-202).

## §10 Thèmes

- **Blocking §5.1** (05 §5.1 l.2931-2956) : un thème **ne** redéfinit **jamais** success/warning/danger/info ; le Focus utilise `success` (break, 05 §3.6.9 l.1072-1073) + `danger` (échec bilan, l.2140-2148) + `info` (réduction notifications, l.2087-2100) → tous **frozen** (jamais redéfinis par thème).
