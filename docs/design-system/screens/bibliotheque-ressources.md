# Écran : bibliotheque-ressources — Bibliothèque de ressources (S-14)

> Module Learning · Route `/learn` (route primaire tab « Apprendre », router.tsx ; WDS 03.4 l'appelle `/library` — écran plein route push, WDS OQ-2 close option A) · SSoT : 05 §4.6.1 l.2479–2519 + WDS 03.4 (03.4-bibliotheque-ressources.md) + docs/learning/overview.md §1–§16 + ADR §13.8/§13.9 + docs/artifacts/overview.md §16/§17 · Statut : détaillé

## §1 Psychologie designer

- **Objectif utilisateur** : centraliser **toute** la matière de travail et d'apprentissage (cours, PDF, documents, images, vidéos, liens, exercices, rapports, notes) rattachée à une matière / compétence / projet / objectif / session, et **sélectionner** la bonne ressource en 2 min pour l'engager en 1 geste — la bibliothèque est le **pont** entre la compréhension (discovery sheet 03.3) et l'engagement (artefact S-36, 03.5) : jamais un flux de liens passifs (garde trigger-map §6, WDS 03.4 §1).
- **Contexte** : mobile Android (Pixel 4a, WDS 03.4), main libre, sessions de fin de journée (23 h, 3G Bénin — WDS 03.4 §3) ; réseau **indifférent** : lecture = miroir local SQLite/PowerSync (AD-7, offline = état premier), la synchronisation cloud est en arrière-plan (05 §4.6.1).
- **Fréquence** : à chaque passage dans la boucle de découverte (ADR §13.9) et lors des sessions de révision — plusieurs fois par semaine ; 2 min de lecture cible (WDS 03.4 §10).
- **État émotionnel cible** : **ciblé, pas submergé** — l'utilisatrice choisit **le cours hydraulique**, pas 50 PDF (WDS 03.4 §3 Hope) ; confiance = la matière est dispo même offline (AD-7).
- **Erreur la plus probable** : re-tomber dans la **veille passive** (Worry, WDS 03.4 §3) — accumuler des liens sans traiter le problème ; l'écran y répond par 1 seul CTA d'action fixe (garde AD-14) et l'état vide **actionnable** (05 §4.6.1).
- **Ce que l'écran RÉSOUT** : une bibliothèque centralisée, **recherchable localement** (SearchBar AD-7) et **récupérable par l'agent** (le kernel AD-12 interroge la bibliothèque, 05 §4.6.1 Objectif), avec le chemin court de sélection → ouverture de l'artefact.

## §2 Contexte fonctionnel

- **Entrée** : depuis `welcome/home` (bloc 4 « Révisions à effectuer », 05 §4.1.2) ; depuis `cours-liste` (05 §4.6.2 Transitions, réf. §4.7.1.2) ; depuis le CTA « Work on this » de la discovery sheet S-40 (WDS 03.4 §2, entrée primaire du scénario 03, ADR §13.9) ; deep link `/learn` (router.tsx).
- **Sortie** : vers `cours-detail` (`/learn/:id`, overlay IonModal sur le tab courant, 02 §6.1 S1/S3, router.tsx) ou vers l'aperçu d'un artefact (`/artifacts/:id`, router.tsx) — l'écran de visualisation AD-10 (docs/artifacts/overview.md §2) ; le CTA « Ouvrir l'artefact » ouvre **directement** S-36 (WDS 03.4 OQ-1 close option A, 09/25) ; retour arrière conserve la sélection (store UI pack 02 §3.2, AD-7 persist, 05 §4.6.1 Transitions).
- **Data** : répertoire local = SQLite/PowerSync (AD-7) ; les artefacts = métadonnées `artifacts` + `r2_key` (docs/artifacts/overview §10) ; pas de HTTP écran-level (job-driven, AD-8).
- **Async** : lecture = **locale** (Skeleton court, pack 02 §7) ; flux serveur = synchronisation R2 des artefacts en arrière-plan + génération via l'agent (AD-12) → seul ce flux peut être `killed` (05 §3.7).
- **Surface** : écran **plein route push** (pas une BottomSheet — matière centralisée, 7 types d'items, WDS 03.4 OQ-2 close option A) ; la BottomNav 5 tabs reste visible (WDS 03.4 §6/OQ-3) ; composition 05 §4.6.1 : **pas** de BottomNav 4 onglets « Bibliothèque/Cours/Fiches/Flashcards » (le tab V1 = « Apprendre » unique, 05 §3.4 l.676 — **OQ-02** §14 : le SSoT écran 05 §4.6.1 ne concorde pas avec la BottomNav 5 items figée, 05 §3.4).
- **Rattachement au gap** (WDS 03.4) : si l'entrée vient d'une sheet S-40, le header porte le titre du gap rattaché (WDS 03.4 §6 : « Gap : Normes hydrauliques Bénin vs Eurocode ») ; sinon = titre générique « Bibliothèque » (05 §4.6.1).

## §4 États (matrice complète AD-13 / 05 §3.7 l.1244–1309)

### (a) 6 états S6 par élément async (ui-libraries §6 l.174–187)

- **loading** (chargement du répertoire local, AD-7) : zone = Skeleton des `ListItem` shape finale (2 blocs groupés + SearchBar + CTA indisponible) ; tokens = --aurora-skeleton (pulse opacité 0.6→1 / 1.2 s, 05 §3.3 l.596, **pas** de shimmer) ; texte exact = « Chargement de la bibliothèque… » (court : local) ; CTA = FAB + CTA « Ouvrir l'artefact » **indisponibles** (WDS 03.4 §7 Loading) ; **entrée** = page transition 200 ms easeOut (PAGE_TRANSITION, ssootCode motionRefs polish.tsx) ; **sortie** = skeleton → contenu crossfade 200 ms (si > 300 ms, contenu partiel en dessous, pack 02 §7).
- **empty** (aucune ressource rattachée) : `EmptyState` (05 §3.3 l.643–655) ; tokens = --aurora-bg-subtle + --aurora-text-secondary ; texte exact = « Aucune ressource pour ce rattachement » ; CTA = « Importer un cours » (primary, ouvre le scanner 04 §3.2) + « Capturer un document » (ghost) — **max 2** (05 §3.3) ; **entrée** = fade 200 ms ; **sortie** = import/capture lancée → flux loading → success.
- **error** (artefact corrompu / illisible) : `Callout danger` inline sur l'item concerné, l'artefact **reste dans la liste** (05 §4.6.1) ; tokens = --aurora-danger / --aurora-danger-surface ; texte exact = « Artefact illisible — aperçu indisponible » ; CTA = « Télécharger » (action alternative, docs/artifacts/overview §17 : conservation du fichier, métadonnées, téléchargement/partage externe **sans** prétendre à une prévisualisation native) ; **entrée** = fade 200 ms ; **sortie** = retry « Réessayer » (re-render aperçu, 05 §3.3 Callout action) ou téléchargement externe.
- **success** (artefact ajouté / import terminé, retour sur l'écran) : Toast `success` 2 s (05 §3.5 l.823, acknowledgement passif, **pas** d'action dedans) ; tokens = --aurora-success ; texte exact = « Ajouté à la bibliothèque » ; CTA = l'item apparaît dans la liste (pas de CTA distinct) ; **entrée** = toast slide up 200 ms (translateY, GPU, S5 l.169) ; **sortie** = auto-dismiss 2 s (05 §3.5 Toast = 2 s, pas 5 s qui est le Snackbar).
- **offline** (réseau coupé, bibliothèque **fonctionnelle** — AD-7 local-first) : Badge info fine « Hors-ligne » (bannière, 05 §3.3 l.639) + Callout info R2 différé (§3 row 4) + `Badge info` « synchronisera à la connexion » sur les artefacts non syncés (05 §4.6.1) ; tokens = --aurora-info / --aurora-warning (frozen) ; texte exact = « La synchronisation des artefacts avec R2 est différée, l'offline reste consultable, AD-7 » (Callout, 05 §4.6.1) ; CTA = FAB « Ajouter » **désactivé si cloud** (05 §3.7 matrice : Button offline = « désactivé si cloud »), le **téléverser** (upload) est cloud ; **capturer** + **créer une note** restent actives (AD-7 local, 05 §3.2 TextField offline) ; le CTA « Ouvrir l'artefact » **reste actionnable** (l'ouverture est locale, la sync de l'engagement est différée, WDS 03.4 §7 Offline/§3 Contrainte UX) ; **entrée** = fade 200 ms ; **sortie** = retour online → resync en arrière-plan (job AD-8) → les badges info disparaissent.
- **killed** (relaunch cold sur flux serveur : sync R2 / génération agent, AD-13/G-M2) : Skeleton + bannière fine « Reconnexion… » ; tokens = --aurora-skeleton + --aurora-danger (badge état) ; texte exact = « Reconnexion… » ; CTA = **aucun** (pas de retry, pas de navigation, 05 §3.7 l.1293–1296 : les données du miroir s'affichent **d'abord**, jamais d'écran blanc) ; **entrée** = fade 200 ms ; **sortie** = reconnexion OK → auto-resync (AD-7) → loading/success ; le répertoire local **ne meurt jamais** (05 §4.6.1 offline).

### (b) États sémantiques §6.1 (ui-libraries l.189–202)

- **en-cours** (sync R2 d'artefacts en cours, job persisté AD-8) : Callout info R2 (§3 row 4) + `Progress` fine sous le Callout (05 §3.3 ProgressBar : charge **déterminée** = pourcentue, pas de glissement indéterminé, l.561) ; tokens = --aurora-info + --aurora-accent-primary ; **pas** de CTA d'attente (le job ne bloque jamais l'UI, AD-8) ; ≠ S6 loading (ici = progression **mesurable**) ; source = ui-libraries §6.1 l.197 + 05 §3.3 l.561–563.
- **terminé** (artefact choisi déjà ouvert / engagement déjà émis, ADR §13.9) : badge `success` « Traité » à côté du CTA (§4b pattern discovery-sheet) ; tokens = --aurora-success ; CTA = « Ouvrir à nouveau l'artefact » (re-sélection possible, 05 §3.3 ListItem selected) ; source = ui-libraries §6.1 l.198.
- **échec** (sync R2 du nouvel artefact **échouée de façon non rétentable**, job terminal — 01 §6 `AppError`) : `Alert` destructive + raison + CTA vers chemin alternatif (« Télécharger le fichier brut », docs/artifacts/overview §17 ; « Partager ») ; tokens = --aurora-danger ; **≠** S6 error (transient, retry in place) ; source = ui-libraries §6.1 l.199 + docs/artifacts/overview §17.
- **succès / erreur générique** = N/A (raison : pas d'écriture **destructive** sur l'écran lui-même — l'écran est une vue de lecture du miroir (AD-7) ; les écritures = ajout local (success = Toast §4a) ou sync différée (échec = §4b) ; pas d'état sémantique d'écran propre, S6 suffit, 05 §3.7 matrice).
- **404/not-found** = §4c ci-dessous (deep link vers ressource supprimée / feature Learning désactivée : `data-state=feature-disabled` + CTA re-enable, ssootCode stateRefs not-found/index.tsx, **jamais** un crash/404 brut).

### (c) 404 / not-found (écran routé `/learn`, oui → règle §6.1 l.202)

- Page entière (route plein, pas overlay — WDS 03.4 OQ-2 option A) : **logo AURORA colorée sans fond, CENTRÉE** (ui-libraries §9.1 l.384–385 : matrice 404 = **COLORED** — « living empty state (primary CTA 'Retour à l'accueil') = active brand » ; le monochrome y est **interdit** : « monochrome version in a 'living' empty state = forbidden », l.390–392 ; **jamais** la version full en in-app, S9 l.352–353) ; message court = « Ressource introuvable » ; CTA primaire = « Retour à l'accueil » (shadcn Button, --aurora-accent-primary, ≥ 44 px, 05 §6.3) ; optionnel secondaire = « Consulter l'écran parent » (§6.1 l.202 : « optional secondary ») ; tokens = --aurora-bg-subtle + --aurora-text-primary ; **entrée** = fade 200 ms easeOut ; **sortie** = tap CTA → `/home` ; source = ui-libraries §6.1 l.202 + §9.1 l.371–405 + 05 §3.1.
- Si preset **Nocturne / High Contrast** actif (§9.1 l.381–382 : monochrome sur ces presets) : le logo 404 passe en **monochrome** SVG (tonal #131B22→#B9BABC, **jamais** sur #121212 brut — posé sur `surface`, l.397–401) ; le preset courant = le thème (AD-17, ssootCode themeRefs), pas l'écran.

### (d) killed sur tout flux serveur (AD-13/G-M2, ui-libraries §6 l.185)

- killed = Skeleton + bannière fine « Reconnexion… » (§4a killed) : **pas** de CTA, **pas** de retry, **pas** de navigation ; tokens = --aurora-skeleton (+ --aurora-danger badge d'état) ; **entrée** = fade 200 ms ; **sortie** = reconnexion → auto-resync (AD-7) → loading/success ; portée = **flux serveur uniquement** : synchronisation R2 des artefacts (jobs AD-8) + génération agent (AD-12) ; le répertoire **local** (SQLite AD-7) est **inchangé** et reste lisible pendant le killed (05 §3.7 l.1294 : « les données du mirror local s'affichent — jamais d'écran blanc ni de reset »).
