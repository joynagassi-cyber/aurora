# Écran : discovery-sheet — Fiche de découverte (S-40, détail d'une `DiscoveryItem`)

> Module Discovery · Route `/discovery/:id` (sheet — ADR §13.8, WDS 03.3 OQ-2 close option A : BottomSheet léger au-dessus du feed S-27, route = identifiant logique/deep-link, **pas** écran plein) · SSoT : WDS 03.3 (03.3-discovery-sheet.md) + ADR §13.8/§13.9 + docs/discovery/overview.md §4/§16 · Statut : additif (inventaire #42, OQ-42 — SSoT écran manquante, additif WDS 03.3)

## §1 Psychologie designer

- **Objectif utilisateur** : rendre un écart **lisible** (compréhension) puis **actionnable en 1 geste** (engagement) : lire les 7+ champs typés de la fiche (ADR §13.8) — pourquoi maintenant, résumé factuel, sources classées par type, ce que ça confirme/contredit, liens cours/domaine pro, compétences, nouveaux concepts, questions ouvertes, actions recommandées, liens arbre/objectifs — puis appuyer sur le CTA unique « Work on this » (ADR §13.9) qui attache le gap à une activité d'apprentissage ou un projet et mène vers la bibliothèque (S-14, 03.4) ou `/learn`/`/tasks` (router.tsx: « Sheet detail → 'work on this' → /learn or /tasks, context-preserving »).
- **Contexte** : mobile Android (Pixel 4a, OQ-11), main libre, session de fin de journée (WDS 03.3 §3 : 23 h, 3G Bénin) ; ouverture par tap sur l'item du feed `/discovery` (03.2, S-27) ou deep link `/discovery/:id` (push depuis le chat S-29, feature-registry §4) ; 2 min de lecture cible (WDS 03.3 §10).
- **Fréquence** : à chaque passage dans la boucle de découverte (ADR §13.9 : observe → search → select → explain → act → measure) — plusieurs fois par semaine, en sessions courtes (WDS 03.3 §1 « 2 min de lecture »).
- **État émotionnel cible** : compréhension (je sais **pourquoi maintenant** et **ce qui est établi vs projeté** — séparation FACT/TREND/ANALYSIS/SCENARIO/UNCERTAINTY, ADR §13.7), confiance (les sources sont classées et traçables), engagement mesurable (1 geste, pas un flux de liens passifs — trap « veille passive », trigger-map §6 via WDS 03.3 §1).
- **Erreur la plus probable** : item introuvable (id invalide / supprimé / non synchronisé dans le miroir local, WDS 03.3 §7 Empty) → état vide actionnable « Revenir au feed » ; ou miroir local corrompu / conflit de sync → bandeau « données locales — resynchronisation en attente » + CTA désactivé (pas d'engagement sur données stale, WDS 03.3 §7 Error).
- **Ce que l'écran RÉSOUT** : le gap resterait un titre flou dans le feed ; la sheet est l'**objet durable** (ADR §13.8 : « chaque découverte importante doit pouvoir devenir un objet durable du système, réutilisable dans l'apprentissage et la planification ») — lire la substance, puis 1 CTA fixe (garde AD-14) qui **ne propose jamais** une liste de liens (garde trigger-map §6) : la compréhension se convertit en engagement mesurable (compris / appliqué / ignoré, ADR §13.9).

## §2 Contexte fonctionnel

- **Entrée** : tap item du feed `/discovery` (03.2 S-27, primaire) ; deep link `/discovery/:id` (chat S-29, secondaire) ; liens depuis arbre sémantique / objectifs = déclarés mais NON COUVERT côté navigation (WDS 03.3 §2 note, scope-report §B).
- **Surface** : **BottomSheet** (WDS 03.3 OQ-2 close, option A ratifiée 09/25 : léger, 2 min, au-dessus du feed — scroll/filtres du feed **préservés**, invariant S6.2 ; la BottomNav 5 tabs est masquée par le sheet) ; le CTA « Work on this » est **fixe en bas du sheet** (WDS 03.3 §6, garde AD-14 : 1 seul CTA d'action, jamais une proposition libre de l'agent).
- **Data** : `DiscoveryItem` (13.8 fields : title, why-now, factual summary, typed sources, confirm/refute, course links, target-domain links, skills, new concepts, open questions, recommended actions, tree/goal links — ADR §13.8) lue depuis le **miroir local PowerSync `discovery_items`** (docs/discovery/overview.md §10, 03 §4.2 ; AD-7/AD-12) ; **pas** de HTTP au niveau écran (overview.md §11 : « job-driven ; UI reads mirrors ; no screen-level HTTP ») ; les sources conservent la provenance (AD-11, overview.md §15) ; `uncertain` marking = Badge quand le `ResearchProvider` dégrade (overview.md §2/§17, 01 §6, AD-1).
- **Écriture** : le CTA « Work on this » émet/attache via l'événement `DiscoveryItemCreated` (overview.md §12 : consommateurs Learning = activité, Knowledge = liens arbre, Progress = measurement, Agent = prochaines recommandations, AD-9 matrix) — l'écran **n'écrit jamais** les lignes `Gap` (Progress les possède, 03 §4.2, overview.md §3) ni les `discovery_items` (Discovery module = owner, l'écran = lecteur du miroir + émetteur de l'engagement).
- **Async** : lecture = **locale** (miroir AD-7 → fast, skeleton ≤ 300 ms, WDS 03.3 §7) ; le flux **serveur** qui existe = les jobs de recherche (multi-source, AD-8) : ils « ne bloquent jamais l'UI » (overview.md §5) et dégénèrent en `uncertain` (AD-1) — killed = relaunch app (05 §3.7, AD-13).

## §4 États (matrice complète AD-13 / 05 §3.7 l.1244–1309)

### (a) 6 états S6 par élément async (ui-libraries §6 l.174–187)

- **loading** (ouverture du sheet, lecture miroir local AD-7) : zone = Skeleton des 3 blocs (shape finale, 05 §3.5 l.803) ; tokens = --aurora-skeleton ; texte exact = « Chargement de la fiche… » (court : lecture locale) ; CTA = « Work on this » **indisponible** (WDS 03.3 §7 Loading) ; **entrée** = ouverture BottomSheet fade 200ms easeOut (PAGE_TRANSITION, ssootCode motionRefs polish.tsx) ; **sortie** = skeleton → contenu crossfade 200ms (pack 02 §7 : si > 300 ms, contenu partiel affiché en dessous).
- **empty** (id invalide / item supprimé / non synchronisé) : `EmptyState` compact dans le sheet ouvert (05 §3.5 l.804) ; tokens = --aurora-bg-subtle + --aurora-text-secondary ; texte exact = « Item introuvable — retour au feed » ; CTA = « Revenir au feed » (WDS 03.3 §7 Empty) → retour `/discovery` (03.2, scroll/filtres préservés, S6.2) ; **entrée** = fade 200ms ; **sortie** = tap CTA → close sheet, retour feed.
- **error** (miroir local corrompu / conflit de sync) : `Callout danger` header (« Données locales — resynchronisation en attente ») + Badge danger « à resync » (pattern 05 §3.3) ; tokens = --aurora-danger / --aurora-danger-surface ; CTA « Work on this » **désactivé** (texte `text-disabled`, WDS 03.3 §7 : engagement interdit sur données stale) ; **entrée** = fade 200ms ; **sortie** = retour réseau + resync OK → flux success, CTA redevient actif ; retry = « Re-synchroniser » (ghost, réapparaît quand réseau OK).
- **success** (fiche lue + engagement émis) : zone = contenu complet + CTA « Work on this » actif ; tokens = --aurora-success (si engagement créé : Toast « Activité créée » 2 s, 05 §3.5 Toast l.823) ; **entrée** = contenu crossfade 200ms ; **sortie** = tap CTA → navigation vers bibliothèque S-14 (03.4) ou `/learn`/`/tasks` (context-preserving, router.tsx) + Toast acknowledgement (2 s, pas d'action, 05 §3.5 l.824).
- **offline** (réseau coupé, sheet ouvert depuis miroir) : Badge info fine « Hors-ligne » sous le handle (AD-13, A5 via WDS 03.3 §7) ; les 3 blocs restent **100 % lisibles** (miroir local, AD-7, docs/discovery/overview §16) ; CTA « Work on this » **reste actionnable** (attachement local, sync différée AD-7 — WDS 03.3 §7) ; tokens = --aurora-info (frozen, 05 §5.1) ; **entrée** = fade 200ms ; **sortie** = retour online → resync en arrière-plan (job, AD-8) → success.
- **killed** (flux serveur : jobs de recherche multi-source, relaunch cold) : Skeleton + bannière fine « Reconnexion… » (§4d) ; tokens = --aurora-skeleton + --aurora-danger (badge état) ; CTA = **aucun** (pas de retry, pas de navigation, ssootCode stateRefs ux-states.tsx : killed = terminal local) ; **entrée** = fade 200ms ; **sortie** = reconnexion OK → auto-resync du miroir (AD-7, 05 §3.7 l.1287–1296 : les données du miroir s'affichent d'abord, **jamais** d'écran blanc) → loading/success ; la lecture locale de la fiche **ne meurt jamais** (AD-7).

### (b) États sémantiques §6.1 (ui-libraries l.189–202)

- **en-cours** (job de recherche multi-source lié à cette fiche en cours, AD-8) : Badge `warning-surface` « Recherche en cours » (le `DataViz` de horizon n'est pas ici, §13) ; tokens = --aurora-warning ; **pas** de CTA d'attente (le job ne bloque jamais l'UI, docs/discovery/overview §5 : « heavy multi-source runs never block the UI ») ; source = ui-libraries §6.1 l.197 + WDS 03.3 §11 (job state 01 §6 loading).
- **terminé** (engagement déjà émis pour cette fiche : activité/projet liée existe, ADR §13.9) : Badge `success` « Traité » à côté du CTA + le CTA devient « Revoir le traitement » (AD-14 « What matters now ? ») ; tokens = --aurora-success ; source = ui-libraries §6.1 l.198 + discovery/overview §12 (`DiscoveryItemCreated` consommé par Learning/Progress).
- **échec** (job de recherche du gap **échoué de façon non rétentable**, provider indisponible durable, G-U4 docs/discovery/overview §21) : `Alert` destructive + raison + CTA vers chemin alternatif (« Ouvrir dans le feed avec d'autres sources », AD-14) ; tokens = --aurora-danger ; **≠** S6 `error` (transient, retry in place) ; source = ui-libraries §6.1 l.199 + 01 §6 (dégénérescence `uncertain`).
- **succès** (feedback transitoire après tap CTA) : Toast `success` 2 s « Activité créée » (05 §3.5 l.823) ; auto-dismiss ; source = ui-libraries §6.1 l.200.
- **erreur** (transient, retryable) = S6 `error` (§4a) — « Réessayer » in place.
- **404/not-found** = §4c ci-dessous (`:id` inconnu ; deep link vers feature découverte désactivée = `data-state=feature-disabled` + CTA re-enable, ssootCode stateRefs not-found/index.tsx, **jamais** un crash/404 brut).

### (c) 404 / not-found (route `/discovery/:id`, oui → règle §6.1 l.202)

- Zone entière du sheet ouvert : **logo AURORA colorée sans fond, centrée** (§9.1 l.378–388 : matrice 404 = COLORED — « living empty state (primary CTA 'Retour à l'accueil') = active brand »), **pas** de fond derrière le logo (S9 l.352–353 : jamais la version full in-app), **pas** de recolor (S9 interdits l.390–392), **pas** de monochrome (état vivant, §9.1 l.390) ; message court = « Fiche introuvable » ; CTA primaire = « Retour à l'accueil » (shadcn Button, --aurora-accent-primary, ≥ 44px, 05 §6.3) + optionnel secondaire « Revenir au feed » (03.2) ; tokens = --aurora-bg-subtle + --aurora-text-primary ; **entrée** = fade 200ms easeOut ; **sortie** = tap CTA → close sheet + navigation (`/home` ou `/discovery`) ; source = ui-libraries §6.1 l.202 + §9.1 l.371–405 + 05 §3.1.

### (d) killed sur tout flux serveur (AD-13/G-M2, ui-libraries §6 l.185)

- killed = Skeleton + bannière fine « Reconnexion… » (§4a killed) : **pas** de CTA, **pas** de retry, **pas** de navigation ; tokens = --aurora-skeleton (+ --aurora-danger badge d'état) ; **entrée** = fade 200ms ; **sortie** = reconnexion OK → auto-resync miroir (AD-7, 05 §3.7 l.1287–1296) ; portée = **flux serveur uniquement** : jobs de recherche multi-source + resync (AD-8, docs/discovery/overview §5/§16 : « new searches need connectivity ») ; la **lecture locale** de la fiche (miroir, AD-7) est **inchangée** et reste utilisable pendant le killed.
