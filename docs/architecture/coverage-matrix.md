## Reading guide

- Status `DOCUMENTED_ONLY` = decided and specified; implementation wave listed in "Impl.".
- Status `DESIGNED_NOT_IMPLEMENTED` = same, with an active contract owner; in the current
  design phase both read as "no code yet".
- Every `Gap / Action` cell pointing to `G-*` / `C-*` / `OQ-*` resolves in
  [gap-register.md](./gap-register.md) or `SPEC.md` open-questions table.
