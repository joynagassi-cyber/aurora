## Consignes
1. Lire d'abord la section « 0. Mode d'emploi » du PRD choisi.
2. Pour chaque écran, ouvrir les images citées (`images/ref_NNN.png`) : la capture fait foi pour la structure, les composants et la disposition.
3. Couleurs, polices, logos, textes de marque : libres, à remplacer par du contenu original.
4. Travailler par phases (voir « plan de livraison » en fin de PRD).
