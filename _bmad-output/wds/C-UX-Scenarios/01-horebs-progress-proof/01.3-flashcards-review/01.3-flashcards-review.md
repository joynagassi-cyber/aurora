## 3. Mental State (step 12)

**Contexte de la page** : Horeb atterrit sur `/flashcards` depuis le CTA « Réviser » de /progress (01.2), 23 h, thème Nocturne, réseau 3G instable. Elle sait qu'elle doit réviser 12 cartes RDM.

| Dimension | Contenu |
|---|---|
| **Trigger** (ce qui la pousse) | Elle vient de lire le dashboard /progress qui lui a signalé le gap RDM + 12 révisions dues — elle veut **réviser pour combler le gap**, pas juste cocher des cases (ADR §18.2, trigger-map §7 signal 8) |
| **Hope** | Terminer la session de 12 cartes et **voir sa SkillState FSRS s'améliorer** (intervalle de révision augmenté, AD-9 `SkillStateChanged`) — la preuve que sa RDM tient le coup, pas juste un score (trigger-map §7 signal 8) |
| **Worry** | Que la session soit **trop longue** (12 cartes, chaque carte prend 30 s-1 min → 6-12 min) et qu'elle abandonne avant le CTA « QCM du domaine » (fatigue nocturne, ADR §23.1, trigger-map §7 signal 15) ; et que le QCM ne soit pas là à la fin (CTA manquant = le chemin est rompu) |
| **Questions** | « Suis-je à la carte 3/12 ou 12/12 ? » · « Combien de temps me reste-t-il avant le QCM ? » · « Le CTA « QCM du domaine » est-il bien là en fin de file ? » |
| **Contrainte UX** | La session est **linéaire** (12 cartes, séquentielles, pas de skip) : chaque carte a une auto-évaluation (FSRS) qui alimente `SkillState` + `ProgressEvidence`. **En fin de file**, le CTA fixe « QCM du domaine » est le **seul CTA d'action** (invariant AD-14, Q8 passo 3) — jamais une proposition libre de l'agent. Offline = état premier (AD-7) : la file de 12 cartes est locale (PowerSync mirror), la session reste actionnable sans réseau. |

## 4. Desired Outcome (step 13)

### Business Goal
**Alimenter le flywheel (trigger-map §5, moteur agentique ADR §18.7) avec 1 `ProgressEvidenceCreated` (AD-9, F-07)** — la session de flashcards produit **≥ 1 preuve vérifiée** (la `ProgressEvidence` de la carte 12/12, ou de la carte « la plus critique ») qui alimente le dashboard Progress (S-13, ADR §18.6). Source : scenario 01 Q7 (Business Success : 4 `ProgressEvidenceCreated` attendus, 1 par surface de preuve), strategic-chains Chaîne 01 Q7, ADR §18, F-07.

### User Goal
**Réviser les 12 cartes RDM dues et terminer par le CTA « QCM du domaine »** — la session est terminée, la `SkillState` FSRS est mise à jour (intervalle augmenté), et elle est **prête pour le QCM** (01.4) sans avoir à chercher elle-même la prochaine action (le CTA fixe la guide). Source : scenario 01 Q4 (Hope), Q8 passo 3, trigger-map §7 signal 8.

## 6. Layout Structure (step 15)

*(PROPOSITION SUGGEST — à confirmer ; NON COUVERT par le corpus gelé pour la disposition interne, dérivé de scope-report S-19 + EXPERIENCE.md Learning loop item 3)*

**Composition flashcards (S-19, session FSRS) — 3 zones fixes (pas un dashboard de widgets) :**

```
+-------------------------------------+
| Flashcards (thème Nocturne)         |
+-------------------------------------+
|  Zone 1 : Progression              |
|  « Carte 3/12 » (badge progression) |
|  + timer session (optionnel)        |
+-------------------------------------+
|  Zone 2 : Carte courante           |
|  +-------------------------------- |
|  | [Face de la carte]              |
|  | (RDM : poutre encastrée)       |
|  |                                  |
|  | [Auto-évaluation FSRS]          |
|  |  (0 = oublié, 1 = difficile,   |
|  |   2 = bonne, 3 = facile)        |
|  +-------------------------------- |
+-------------------------------------+
|  Zone 3 : En fin de file (12/12)   |
|  CTA FIXE : [QCM du domaine]       |
|  → `qcm` (01.4)                    |
+-------------------------------------+
|  BottomNav (5 tabs, S-31 shared)   |
|  Home · Kanban · Calendar ·        |
|  Progress · /agent                 |
+-------------------------------------+
```

**Note** : Les 3 zones sont fixes (pas de widgets dynamiques, pas de proposition d'agent). La **Zone 1** affiche la progression (carte 3/12) + un timer optionnel (si Horeb veut voir le temps écoulé). La **Zone 2** est la carte courante (face + auto-évaluation FSRS à 4 niveaux : oublié/difficile/bonne/facile). La **Zone 3** n'apparaît **qu'en fin de file (carte 12/12)** : le CTA fixe « QCM du domaine » est le **seul CTA d'action** de la surface (invariant AD-14, Q8 passo 3) — jamais une proposition libre de l'agent.

## 7. Page States (AD-13, 5 états canoniques)

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| **Default** | File due > 0 (12 cartes RDM), session en cours | 3 zones : progression (3/12), carte courante, (Zone 3 masquée jusqu'à 12/12) | Tap sur carte → auto-évaluation FSRS ; tap sur CTA (en fin de file) → `qcm` (01.4) |
| **Loading** | Charge de la file (PowerSync mirror local, AD-7) | Skeleton des 3 zones (~300 ms max, AD-13), CTA indisponible | — |
| **Empty** | File due = 0 (aucune carte à réviser) | État vide actionnable : « Aucune carte due » + CTA « Revenir à /progress » (retour natif) | Tap sur CTA → `/progress` (01.2) |
| **Error** | Sync hors-ligne + file corrompue | Bandeau « hors-ligne — dernières données locales » (AD-7 : offline = état premier, pas un échec), file lue en read-only depuis le mirror local | Tap quand réseau revenu |
| **Offline** (AD-7) | Réseau coupé, file chargée depuis le mirror local | Bandeau fine « hors-ligne » (AD-13, A5), session reste **actionnable** (la file de 12 cartes est locale) | Tap sur carte → auto-évaluation ; tap sur CTA (en fin de file) → `qcm` (01.4) |
