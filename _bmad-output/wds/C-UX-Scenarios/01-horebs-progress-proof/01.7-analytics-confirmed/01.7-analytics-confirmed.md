## 6. Layout Structure (step 15)

*(PROPOSITION SUGGEST — à confirmer ; NON COUVERT par le corpus gelé pour la disposition interne, dérivé de ADR §18.6 « 5 questions structurées, pas un dashboard de KPIs »)*

**Composition /progress (S-13, ADR §18.6) — 5 questions structurées, état post (4 preuves affichées) :**

```
+-------------------------------------+
| /progress (thème Nocturne, sombre)  |
+-------------------------------------+
| 1. « Où en suis-je ? »             |
|    → État courant : RDM = mastered  |
|    (5/5 dimensions : compre/        |
|     rappel/appl/auton/retention)    |
|    ✓ preuve S-19 (flashcards)       |
+-------------------------------------+
| 2. « Comment ça a évolué ? »       |
|    → Tendance : progression         |
|    (gap RDM comblé)                 |
|    ✓ preuve S-20 (QCM)             |
+-------------------------------------+
| 3. « Pourquoi ? » (causes)         |
|    → Causes comblées :              |
|    (a) transfert (poutre encastrée) |
|    (b) 12 révisions FSRS dues       |
|    ✓ preuve S-22 (miroir cognitif)  |
+-------------------------------------+
| 4. « Que dois-je faire ? »         |
|    → CTA FIXE : [Terminer]          |
|    (scénario success ✓)             |
|    ✓ preuve S-38 (exercices)        |
+-------------------------------------+
| 5. « Comment je le prouve ? »      |
|    → 4 événements ProgressEvent     |
|    (AD-9) produits cette session :  |
|    S-19 · S-20 · S-22 · S-38 ✓     |
+-------------------------------------+
|  BottomNav (5 tabs, S-31 shared)   |
|  Home · Kanban · Calendar ·        |
|  [Progress] · /agent               |
+-------------------------------------+
```

**Note** : Les 5 questions sont des **sections actionnables** (pas des KPIs) : chaque question a une réponse lisible + une action éventuelle. **État post** : les 4 preuves (S-19/20/22/38) sont **affichées** dans les 5 questions, avec le badge ✓. La question 4 a le CTA fixe « Terminer » (scénario success ✓) — **pas un CTA vers une autre surface** (le scénario est terminé). Les 4 critères mesurables Q7 sont **visibles** : (a) score QCM ≥ 80 % avec distinction reconnaissance/transfert (question 2), (b) exercice validé Scientific Engine (question 4), (c) NodeState `mastered` poutre encastrée (question 1), (d) SkillState FSRS à intervalle augmenté (question 1, dimension retention).
