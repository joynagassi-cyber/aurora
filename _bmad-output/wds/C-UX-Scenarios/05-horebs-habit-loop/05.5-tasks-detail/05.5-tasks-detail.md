## 1. Page Purpose (step 10)

**Wording proposé (09/25) :**
> Horeb ouvre l'**overlay de détail `/tasks/:id` (S-24)** depuis le tap sur la `KanbanCard` de sa tâche nocturne sur le board Kanban (05.4, S-05) — l'overlay s'ouvre en **`BottomSheet full` par-dessus le board** (le Kanban **reste** visible en arrière-plan, pack 05 §4.3.3, règle de non-surprise). ## 3. Mental State (step 12)

**Contexte de la page** : 23 h 10, chambre, Pixel 4a, thème Nocturne, réseau 3G Bénin instable (AD-7, offline = état premier). Horeb vient de glisser sa tâche nocturne vers « en cours » sur le board Kanban (05.4). Elle est fatiguée, elle veut **fermer proprement** sa routine du soir et **lancer le focus** sur la tâche nocturne — sans y ajouter de widget ni attendre le réseau.

## 4. Desired Outcome (step 13)

### Business Goal
**Régularité mesurée (fidélisation) : le cycle de productivité est concret et visible** — l'overlay de détail est la **preuve** que la tâche nocturne **a été positionnée Q1** (matrice Eisenhower, `docs/productivity/eisenhower.md` §4 : quadrant computé depuis les champs AD-15, pas stocké) ; le CTA focus **enclenche** la session de travail profond (trigger-map §2 Envie ① Focus) — chaque **action** mesurée, pas un compteur de tâches (BG-PRIMARY, scénario 05 Q2 ; ADR §18.2 transformation dans le temps ; trigger-map §1 Primary ; ADR §2 cycle de productivité). Source : strategic-chains Chaîne 05 Q8 passo 5 ; `docs/productivity/eisenhower.md` §4 (user flows : intent → success → CTA focus).

### User Goal
**Lire les sous-tâches de sa tâche nocturne et lancer le focus en 1 geste, hors-ligne** — l'overlay est **local et immédiat** (AD-7, pack 03 §5.5 : mirror PowerSync, sync au retour) ; Horeb **voit** les 3 sous-tâches (liste compacte `RoutineStep`-style) et la **position Q1** (mini-matrice, 4 cases) et **tape le CTA fixe « Lancer le focus »** — la transition vers la vue Eisenhower (05.6, S-39) est **instantanée**, le check-in du jour est **bouclé**, la régularité est **mesurée**. Source : scénario 05 Q4 (Hope), Q8 passo 5 ; pack 05 §4.3.3 (transition Card → BottomSheet full) ; `docs/productivity/eisenhower.md` §4 (CTA focus après placement Q1).
