- **Le FAB chat S-29** (OQ-4) est **masqué** sur la matrice (le 5ᵉ tab BottomNav est l'entrée principale ; la matrice a une BottomNav, le FAB chat est masqué — option C, close 09/25).
- **Pas de « widget » dans la matrice** (trigger-map §6 trap « Surcharge de widgets ») : les 4 quadrants sont **compètes** mais **pas un dashboard** — le CTA focus est le **seul** CTA d'action (AD-14).
