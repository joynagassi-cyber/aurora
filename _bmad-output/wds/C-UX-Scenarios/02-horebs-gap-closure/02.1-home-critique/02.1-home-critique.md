## 1. Page Purpose (step 10)

**Wording proposé (09/25) :**
> Horeb ouvre l'app et lit le bloc « **suggestions Coach** » (7ᵉ item fixe de la composition AD-14) qui lui signale un **écart professionnel documenté** : « Tu n'as pas encore de jalon pro validé sur l'objectif bureau d'études ». Le **CTA unique et fixe** de ce bloc l'amène vers `objectifs-liste` (S-06) — jamais un dashboard de widgets (AD-14, ADR §12, trigger-map §6 trap « surcharge de widgets »).

La page ne fait qu'une seule chose à chaque ouverture : **faire émerger le point critique (écart pro) et le rendre actionnable en 1 geste vers l'objectif**.

## 3. Mental State (step 12)

**Contexte de la page** : Horeb atterrit sur Home à 23 h, seule dans sa chambre, thème Nocturne, réseau 3G instable. Elle vient d'ouvrir l'app.

| Dimension | Contenu |
|---|---|
| **Trigger** (ce qui la pousse) | La crainte viscérale d'être à l'étroit entre son niveau académique (BA/RDM/hydraulique) et le métier réel de bureau d'études (trigger-map §7 signal 12, ADR §13.4) ; l'espoir de mesurer l'écart **documenté** plutôt que de le supposer (trigger-map §7 signal 14, ADR §13.5) |
| **Hope** | Ouvrir une voie concrète vers l'excellence internationale, en voyant l'écart documenté se réduire jalon par jalon (trigger-map §7 signal 14, Envie) |
| **Worry** | Être piégée dans le programme universitaire sans jamais mesurer l'écart réel avec le métier de bureau d'études (trigger-map §7 signal 12, Douleur ; peur ① « Illusion de progression », ADR §18.2) |
| **Questions** | « Quel est mon écart le plus critique par rapport au bureau d'études ? » · « Y a-t-il un jalon pro à valider cette semaine ? » · « Qu'est-ce que je dois faire *maintenant* pour réduire cet écart ? » |
| **Contrainte UX** | Offline = état premier (AD-7) : si le réseau est coupé, le bloc « suggestions Coach » doit rester lisible avec les dernières données locales (PowerSync mirror), et le CTA reste actionnable |

## 4. Desired Outcome (step 13)

### Business Goal
**Mesurer l'écart documenté (académique ↔ professionnel ↔ international) et le réduire par un plan d'ouverture (learning + practice), avec preuves de compétence construites progressivement** — le bloc « suggestions Coach » est le point de départ de la chaîne 02 (gap-closure) : il alimente le moteur agentique (ADR §13.5, trigger-map §5) qui détecte l'écart pro et déclenche l'objectif professionnel. Source : scenario 02 Q7 (Business Success), strategic-chains Chaîne 02 Q7, ADR §13.5.

### User Goal
**Percevoir l'écart pro (jalon bureau d'études non validé) en un coup d'œil et l'actionner en 1 geste** vers `objectifs-liste` (S-06) pour découvrir *pourquoi* son objectif pro est en retard. Source : scenario 02 Q4 (Hope), Q8 passo 1, trigger-map §7 signal 14.

## 6. Layout Structure (step 15)

*(PROPOSITION SUGGEST — dérivée de la spec 01.1 + spine AD-14 + trigger-map §6 trap « surcharge de widgets »)*

**Composition Home fixe AD-14 — 7 items ordonnés et fixes** (agenda, prochaine action, priorité, progression critique, révisions dues, accès Focus, suggestions Coach) : **jamais un tableau de bord de widgets, jamais un 8ᵉ item**. Le bloc « **suggestions Coach** » (7ᵉ item) est le **CTA unique et fixe** de cette transition dans le contexte du **scénario 02** (gap-closure) — il mène vers `objectifs-liste` (S-06).

```
+-------------------------------------+
| Home (thème Nocturne, fond sombre)  |
+-------------------------------------+
| 1. Agenda (aujourd'hui)            |
+-------------------------------------+
| 2. Prochaine action                 |
+-------------------------------------+
| 3. Priorité                         |
+-------------------------------------+
| 4. Progression critique            |
|    → « RDM : gap détecté,          |
|       12 révisions dues »  [CTA]   |  ← contexte scénario 01 (chaîne 1)
+-------------------------------------+
| 5. Révisions dues (12)             |
+-------------------------------------+
| 6. Accès Focus                     |
+-------------------------------------+
| 7. Suggestions Coach               |
|    → « Jalon pro bureau d'études   |
|       non validé »  [CTA]          |  ← contexte scénario 02 (chaîne 2)
+-------------------------------------+
|  [FAB chat S-29] (back-up global)  |  ← option C : FAB sur les écrans sans BottomNav
+-------------------------------------+
|  BottomNav (5 tabs, S-31 shared)   |
|  Home · Kanban · Calendar ·        |
|  Progress · /agent                 |  ← 5ᵉ = chat S-29 (OQ-4 close, option C)
+-------------------------------------+
```

**Note** : Les 7 items AD-14 sont **les mêmes** dans les scénarios 01 et 02. Ce qui change est **le bloc actionné** : dans le scénario 01 (chaîne 1 : progress-proof), c'est le bloc item 4 (« progression critique » → `/progress` → `flashcards` → `qcm` → `mirror` → `exercises` → `/progress` post). Dans le scénario 02 (chaîne 2 : gap-closure), c'est le bloc item 7 (« suggestions Coach » → `objectifs-liste` → `objectifs-detail` → `projets-detail` → `timeline-gantt` → `fiches-liste` → `fiches-detail` ✓). **Le chemin est le seul chemin** (invariant AD-14) : l'utilisateur n'a aucune décision de branchement à prendre.

## 7. Page States (AD-13, 5 états canoniques)

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| **Default** | Profil `UserContext` actif, chemin en cours | 7 blocs AD-14, bloc « suggestions Coach » visible + badge « Jalon pro non validé » | Tap sur le bloc → `objectifs-liste` (02.2) |
| **Loading** | Charge du bloc (PowerSync mirror local, AD-7) | Skeleton des 7 blocs (~300 ms max, AD-13), CTA indisponible | — |
| **Empty** | Aucun écart pro détecté + aucun jalon à valider (état sain) | Bloc « suggestions Coach » neutre / masqué | Pas de CTA d'action (le chemin ne démarre pas) |
| **Error** | Sync hors-ligne + bloc corrompu | Bandeau « hors-ligne — dernières données locales » (AD-7), bloc lu en read-only depuis le mirror local | Tap quand réseau revenu |
| **Offline** (AD-7) | Réseau coupé, blocs chargés depuis le mirror local | Bandeau fine « hors-ligne » (AD-13, A5), CTA du bloc « suggestions Coach » reste **actionnable** | Tap sur le bloc → `objectifs-liste` (02.2) |
