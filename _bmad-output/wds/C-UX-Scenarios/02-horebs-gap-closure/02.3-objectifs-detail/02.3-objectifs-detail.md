## 1. Page Purpose (step 10)

**Wording proposé (09/25) :**
> Horeb lit l'objectif pro (bureau d'études) avec sa hiérarchie (projets qui y contribuent), ses indicateurs et ses jalons — **l'écart se lit ici** : jalons non atteints vs indicateurs. Le **CTA unique et fixe** « ouvrir le projet » l'amène vers `projets-detail` (S-04) — jamais une proposition libre de l'agent (invariant AD-14, Q8 passo 3).

La page ne fait qu'une seule chose : **montrer l'objectif pro avec sa hiérarchie et rendre le projet actionnable en 1 geste**.

## 3. Mental State (step 12)

**Contexte de la page** : Horeb atterrit sur `/goals/:id` depuis la Card 2 (pro) de `objectifs-liste` (02.2), 23 h, thème Nocturne, réseau 3G instable. Elle sait qu'elle a un écart pro et veut le **documenter** (pas juste le constater).

| Dimension | Contenu |
|---|---|
| **Trigger** (ce qui la pousse) | Elle vient de repérer l'objectif pro (bureau d'études) qui porte l'écart documenté (badge « En retard ») — elle veut **comprendre pourquoi** l'écart existe (jalons non atteints vs indicateurs) et **le réduire** (pas juste le mesurer) (trigger-map §7 signal 12, ADR §13.4) |
| **Hope** | Voir la hiérarchie (projets qui y contribuent), les indicateurs et les jalons — et **identifier le jalon précis** qui précipite l'écart (pas un compte abstrait, ADR §18.2) ; l'espoir de mesurer l'écart documenté plutôt que de le supposer (trigger-map §7 signal 14, ADR §13.5) |
| **Worry** | Que les jalons non atteints **ne soient pas documentés** (piège peur ①, ADR §18.2) et qu'elle reparte sans savoir *quelle action* va réduire l'écart ; et que le CTA « ouvrir le projet » ne l'amène pas vers la bonne surface (`projets-detail` S-04, pas `timeline-gantt` S-33) |
| **Questions** | « Quels jalons sont non atteints ? » · « Quel est le jalon précis qui précipite l'écart ? » · « Le CTA « ouvrir le projet » mène-t-il bien vers `projets-detail` ? » |
| **Contrainte UX** | La page montre **la hiérarchie** (projets qui y contribuent), **les indicateurs** et **les jalons** — l'écart se lit ici (jalons non atteints vs indicateurs). Le **CTA unique et fixe** « ouvrir le projet » est l'unique action de sortie (invariant AD-14, Q8 passo 3) — jamais une proposition libre de l'agent. Offline = état premier (AD-7) : les objectifs sont **stockés localement** (PowerSync mirror), la page reste lisible. |

## 4. Desired Outcome (step 13)

### Business Goal
**Documenter l'écart (académique ↔ pro ↔ international) et le réduire par un plan d'ouverture (learning + practice)** — la page `objectifs-detail` est le **point de documentation** de la chaîne 02 : elle alimente le moteur agentique (ADR §13.5, trigger-map §5) qui détecte l'écart pro et déclenche le plan d'ouverture. Source : scenario 02 Q7 (Business Success), strategic-chains Chaîne 02 Q7, ADR §13.5.

### User Goal
**Documenter l'écart (jalons non atteints) et l'actionner en 1 geste** vers `projets-detail` (S-04) pour construire le plan d'ouverture. Source : scenario 02 Q4 (Hope), Q8 passo 3, trigger-map §7 signal 14.

## 6. Layout Structure (step 15)

*(PROPOSITION SUGGEST — NON COUVERT par le corps gelé pour la disposition interne, dérivé de scope-report S-07 + Screen Registry §A #7 §4.3.4)*

**Composition objectifs-detail (S-07) — 3 sections verticales (pas un dashboard de widgets) :**

```
+-------------------------------------+
| /goals/:id (thème Nocturne, sombre) |
|  Titre : « Valider jalon pro        |
|    bureau d'études : RDM appliqué » |
|  [Statut : En retard]              |
+-------------------------------------+
|  Section 1 : Hiérarchie             |
|  → Projets qui y contribuent :      |
|    • « RDM ch.5 — poutre encastrée »|
|    • « Hydraulique — calcul débit » |
+-------------------------------------+
|  Section 2 : Indicateurs            |
|  → 2 indicateurs :                 |
|    (a) Score QCM RDM ≥ 80 %        |
|    (b) Exercice validé SciEngine   |
+-------------------------------------+
|  Section 3 : Jalons                 |
|  → 4 jalons :                     |
|    • Jalon 1 : ✓ atteint           |
|    • Jalon 2 : ✓ atteint           |
|    • Jalon 3 : ✗ non atteint ←      |  ← l'écart se lit ici
|    • Jalon 4 : ✗ non atteint ←      |  [MISE EN AVANT, OQ-1 close A]
|    [CTA FIXE : Ouvrir le projet]    |
|    → `projets-detail` (02.4)       |
+-------------------------------------+
|  BottomNav (5 tabs, S-31 shared)   |
|  Home · Kanban · Calendar ·        |
|  Progress · /agent                 |
+-------------------------------------+
```

**Note** : Les 3 sections sont **verticales fixes** (pas de widgets dynamiques, pas de proposition d'agent). La **Section 1** montre la hiérarchie (projets qui y contribuent). La **Section 2** montre les indicateurs (mesurables, ADR §18.2). La **Section 3** montre les jalons (atteints vs non atteints) — **l'écart se lit ici** (jalons non atteints vs indicateurs). Le **CTA fixe** « Ouvrir le projet » est le **seul CTA d'action** de la surface (invariant AD-14, Q8 passo 3) — jamais une proposition libre de l'agent.

## 7. Page States (AD-13, 5 états canoniques)

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| **Default** | Objectif pro stocké localement (PowerSync mirror), jalons non atteints visibles | 3 sections : hiérarchie, indicateurs, jalons (2 non atteints) + CTA « Ouvrir le projet » | Tap sur CTA → `projets-detail` (02.4) |
| **Loading** | Charge de l'objectif (PowerSync mirror local, AD-7) | Skeleton des 3 sections (~300 ms max, AD-13), CTA indisponible | — |
| **Empty** | Pas de jalon sur l'objectif (objectif créé mais pas encore scindé en jalons) | État vide actionnable : « Pas de jalon — ajoutons un jalon » + CTA « Créer un jalon » (hors chemin, invariant AD-14) | Tap sur CTA → création de jalon (hors scénario) |
| **Error** | Sync hors-ligne + objectif corrompu | Bandeau « hors-ligne — dernières données locales » (AD-7), 3 sections lues en read-only depuis le mirror local | Tap quand réseau revenu |
| **Offline** (AD-7) | Réseau coupé, objectif chargé depuis le mirror local | Bandeau fine « hors-ligne » (AD-13, A5), CTA « Ouvrir le projet » reste **actionnable** | Tap sur CTA → `projets-detail` (02.4) |
