## 1. Page Purpose (step 10)

**Wording proposé (09/25) :**
> Horeb arrive de la bibliothèque (03.4, S-14) avec le cours hydraulique ciblé par la découverte (« Normes hydrauliques Bénin vs Eurocode », §4.3.2) sélectionné comme `SourceRef`. Elle **ouvre l'artefact de document** et accède à sa **vue détaillée** : la prévision (ce que cet artefact couvre, chapitres/notions concernées), les métadonnées (type, origine, lien au gap de la sheet S-40, dernière synchronisation) et les **actions fixes** (l'artefact est local, lecture depuis le mirror PowerSync AD-7). Le **CTA « Ouvrir dans /learn »** est le geste unique qui l'envoie vers le **flow d'apprentissage S-25 (`/learn`), puis cours-detail S-16 (03.6)** — le chemin le plus court vers l'engagement d'apprentissage tracé (preuve : position de cours persistée S-25, trigger-map §7 signal 8). La vue détail est le **pont entre la sélection (03.4) et l'engagement (03.6)**, jamais un flux de liens passifs.

La page fait une seule chose : **rendre l'artefact lisible et engagé en 1 geste** — c'est le pont entre la bibliothèque (S-14, 03.4) et le flow d'apprentissage (S-25 + S-16, 03.6). Sans cette vue, l'artefact reste un item de liste ; avec elle, Horeb vérifie **ce que le cours couvre** (prévision) avant de s'engager, puis ouvre `/learn` avec la bonne position.

## 3. Mental State (step 12)

**Contexte de la page** : Horeb a tap « Ouvrir l'artefact » dans la bibliothèque (03.4), 23 h, thème Nocturne, Pixel 4a, 3G Bénin. Elle est dans un **état de vérification** : avant de s'engager dans `/learn`, elle veut savoir **ce que cet artefact couvre** (prévision : chapitres, notions rattachées au gap) et **d'où il vient** (métadonnées : origine, lien au gap « Normes hydrauliques Bénin vs Eurocode ») — pas un bloc opaque (séparation strictes ADR §13.7, lisibilité 2 min).

| Dimension | Contenu |
|---|---|
| **Trigger** (ce qui la pousse) | Elle a sélectionné le cours hydraulique comme `SourceRef` (ADR §13.9, scenario 03 passo 4) et doit maintenant **vérifier la prévision de l'artefact** (ce qu'il couvre vs son gap) avant l'engagement dans `/learn` — le gap doit rester **lisible** (pas un bloc factuel opaque, trigger-map §7 signal 11, ADR §13.4) |
| **Hope** | Comprendre en 2 min : ce que le cours hydraulique **couvre** (prévision), pourquoi il est **ciblé par la découverte** (métadonnées, lien au gap S-40), et ouvrir `/learn` avec la **bonne position de cours persistée** (S-25, 03.6) pour commencer l'apprentissage — trigger-map §7 signal 13 (différenciation professionnelle au Bénin) |
| **Worry** | Re-tomber dans la veille passive : ouvrir l'artefact et **accumuler une référence sans jamais traiter le problème** (trigger-map §7 signal 4, Peur ② « veille passive », ADR §13, §17) — la vue détail doit **proposer une action (CTA fixe « Ouvrir dans /learn »)** plutôt que multiplier les références ; et la prévision rester **lisible** (pas une liste de métadonnées brutes) |
| **Questions** | « Que couvre ce cours exactement (chapitres / notions) ? » · « Est-ce bien le cours ciblé par ma découverte (gap) ? » · « Puis-je l'ouvrir dans /learn immédiatement ? » · « Quelle est ma position de cours actuelle (persistée S-25) ? » |
| **Contrainte UX** | Offline = état premier (AD-7) : l'artefact est lu depuis le **mirror local PowerSync** (la `SourceRef` + les métadonnées sont stockées localement, pas un fetch réseau) ; la prévision et les métadonnées restent lisibles sans réseau. Le CTA « Ouvrir dans /learn » reste **actionnable offline** (l'ouverture du flow `/learn` est locale ; la synchronisation de la position de cours S-25 est différée, AD-7). |

## 4. Desired Outcome (step 13)

### Business Goal
**Conversion de la sélection d'artefact en engagement d'apprentissage mesurable** — la vue détail est le point de passage du sous-cycle **Knowledge → Learning** (trigger-map §5, ADR §13.9) : lire la prévision (vérification) puis « Ouvrir dans /learn » (engagement) crée l'activité d'apprentissage qui relie le gap (S-40) au savoir existant (S-14 → S-36) et se mesure ensuite (position de cours persistée S-25, compris / appliqué / ignoré, ADR §13.9). Source : scénario 03 Q7 (Business Success : 1 sheet traitée rattachée à 1 ressource S-14 et 1 position S-25), ADR §13.9, discovery-gap-pipeline.md §3.

### User Goal
**Vérifier la prévision de l'artefact en 2 min et l'engager en 1 geste vers /learn (S-25, 03.6)** — Horeb sort de la vue détail avec : (a) la **prévision** de l'artefact (ce que le cours hydraulique couvre, chapitres/notions — §4.3.2) et les **métadonnées** (type, origine, lien au gap, sync AD-7), et (b) le **geste unique** « Ouvrir dans /learn » qui l'ouvre dans le flow d'apprentissage S-25 avec la position de cours persistée (03.6, S-16 cours-detail). Source : scénario 03 Q4 (Hope), Q8 passo 5, ADR §13.9.

> - **A** : la vue détail reste **lisible** pendant le focus, mais le CTA « Ouvrir dans /learn » est **désactivé (grisé)** — cohérent avec la variante Focus de 01.1 (CTA désactivé si focus en cours) ; recommandé, ne brise pas le focus.

> - **C** : la vue détail est lisible + CTA actif, mais l'engagement « Ouvrir dans /learn » est **reporté dans la file de tâches du focus** — NON COUVERT (aucune file de tâches du focus dans le corps gelé, ne pas inventer).

## 6. Layout Structure (step 15)

*(PROPOSITION SUGGEST — dérivée de ADR §13.9 + trigger-map §6 + garde AD-14)*

**La vue détail est une route push `/library/:id` (écran plein)** qui s'ouvre **au-dessus de la bibliothèque S-14** (la bibliothèque reste en arrière-plan, scroll/filtres préservés — invariant S6.2). La composition est **lue d'abord vérifiée puis engagée** : la prévision de l'artefact (ce que le cours hydraulique couvre, chapitres/notions — §4.3.2) et les métadonnées (type, origine, lien au gap, sync AD-7) sont groupées en **2 blocs**, et le CTA « Ouvrir dans /learn » est **fixe en bas d'écran** (garde AD-14 : CTA fixe, jamais une proposition libre de l'agent dans le chemin court).

```
+-------------------------------------+
|  [bibliothèque S-14 en              |
|   arrière-plan,                      |  ← invariant S6.2
|   scroll/filtres préservés]          |
+-------------------------------------+
|  ←  Cours hydraulique ciblé         |  ← header (route push /library/:id)
|       (artefact S-36, §4.3.2)       |
|                                     |
|  ── BLOC 1 · PRÉVISION ────────────  |
|  • Chapitres / notions couvertes    |
|  • Lien au gap (S-40)               |
|    « Normes hydrauliques Bénin       |
|       vs Eurocode »                 |
|                                     |
|  ── BLOC 2 · MÉTADONNÉES ──────────  |
|  • Type : cours (SourceRef S-14)    |
|  • Origine / source                 |
|  • Dernière sync (AD-7, mirror)     |
|                                     |
|  [CTA FIXE] « Ouvrir dans /learn »  |  ← ADR §13.9 — ouvre S-25 (03.6)
|     → /learn S-25 → cours-detail    |     puis S-16 cours-detail
|         S-16 (03.6)                 |
+-------------------------------------+
|  (BottomNav 5 tabs S-31 visible    |
|   sur la route push /library/:id)   |
+-------------------------------------+
```

**Note** : La prévision (chapitres/notions du cours hydraulique, §4.3.2) et les métadonnées (type, origine, lien au gap, sync AD-7) sont **groupées en 2 blocs** pour la lisibilité 2 min. Le CTA « Ouvrir dans /learn » est le **seul CTA d'action** (garde AD-14) : il **ouvre le flow d'apprentissage S-25 (`/learn`), puis cours-detail S-16 (03.6)** avec la position de cours persistée (S-25) et mène vers l'engagement d'apprentissage (ADR §13.9). Le CTA est **fixe** — jamais une proposition libre de l'agent dans le chemin court. La preview par format (S-28 `/artifacts/:id`, « jamais de preview factice ») est **déclarée (pont) mais NON COUVERT** côté spec de page propre (référencée sans section propre, scope-report §B) ; la paire S-28/S-36 reste documentée, pas dupliquée.
