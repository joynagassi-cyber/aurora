## 3. Mental State (step 12)

**Contexte de la page** : Horeb a tap « Ouvrir dans /learn » dans la vue détail (03.5), 23 h, thème Nocturne, Pixel 4a, 3G Bénin (ou hors-ligne — AD-7, l'état premier). | Dimension | Contenu |

| **Trigger** (ce qui la pousse) | Le CTA « Ouvrir dans /learn » (03.5, ADR §13.9) a déposé le cours hydraulique comme cible ; le flow S-25 doit l'ouvrir **avec la position de cours persistée** — « s'ouvre avec position de cours persistée et recommandations ciblées affichées » (Surfaces §1 #7, Adr 18.3) — pour qu'elle localise le chapitre du gap et le tapote pour commencer (passo 7 du scénario 03) |

Source : scénario 03 Q4 (Hope), Q8 passo 7, Surfaces §1 #7.
