## 1. Page Purpose (step 10)

**Wording proposé (09/25) :**
> Horeb arrive de la sheet de découverte (03.3, S-40) avec le gap « **Normes hydrauliques Bénin vs Eurocode** » attenant à son profil. La bibliothèque **centralise toute la matière** rattachée à ce gap : cours, PDF, docs, images, vidéos, liens, notes — chaque item étant typé et localisable via le **mirror PowerSync local (AD-7)**. Elle **sélectionne la ressource d'apprentissage `SourceRef`** (le cours hydraulique ciblé par la découverte, ADR §13.9) et le **CTA « Ouvrir l'artefact »** l'envoie vers **artefacts-detail (S-36, 03.5)** — le chemin le plus court vers l'engagement d'apprentissage (trigger-map §6, pas de veille passive). La bibliothèque est le **pont concret** entre la compréhension (sheet 03.3) et l'action (engagement 03.5), jamais un flux de liens passifs.

La page fait une seule chose : **rendre la matière sélectionnable et engagée en 1 geste** — c'est le pont entre la sheet (03.3) et l'artefact (03.5). Sans cette bibliothèque, le gap reste un titre flou ; avec elle, Horeb choisit **la bonne ressource** (cours, pas un lien quelconque) et l'ouvre.

## 3. Mental State (step 12)

**Contexte de la page** : Horeb a tap « Work on this » dans la sheet (03.3), 23h, thème Nocturne, Pixel 4a, 3G Bénin. Elle est dans un **état de sélection** : elle a compris le gap (pourquoi maintenant, ce qui est confirmé/contesté), et maintenant elle doit **choisir la bonne ressource** parmi la matière centralisée — pas un lien au hasard, mais le cours hydraulique ciblé (ADR §13.9, trigger-map §7 signal 13 « différenciation professionnelle au Bénin »).

| Dimension | Contenu |
|---|---|
| **Trigger** (ce qui la pousse) | L'écart flou entre le programme suivi et les compétences réellement utilisées au métier réel (trigger-map §7 signal 11, ADR §13.4) ; elle a compris la substance dans la sheet, maintenant elle doit **sélectionner l'engagement** (cours, pas un lien) — ADR §13.9 : « crée éventuellement une activité d'apprentissage **ou** un projet » |
| **Hope** | Trouver **le cours hydraulique** (pas 50 PDF) en 2 min, le sélectionner comme `SourceRef`, et l'ouvrir dans l'artefact (S-36, 03.5) pour commencer l'apprentissage — trigger-map §7 signal 13 (différenciation professionnelle au Bénin) |
| **Worry** | Re-tomber dans la veille passive : ouvrir la bibliothèque et **accumuler des liens sans jamais traiter le problème** (trigger-map §7 signal 4, Peur ② « veille passive », ADR §13, §17) — la bibliothèque doit **proposer une action (CTA fixe « Ouvrir l'artefact »)** plutôt que multiplier les références ; et le gap rester **lisible** (pas un bloc factuel opaque) |

## 4. Desired Outcome (step 13)

### Business Goal
**Conversion de la sélection en engagement d'apprentissage mesurable** — la bibliothèque est le point de passage du sous-cycle **Discovery → Knowledge → Learning** (trigger-map §5, ADR §13.9) : lire la sheet (compréhension) puis « Ouvrir l'artefact » (engagement) crée l'activité d'apprentissage ou projet qui relie le gap au savoir existant et se mesure ensuite (compris / appliqué / ignoré, ADR §13.9). Source : scénario 03 Q7 (Business Success : 1 sheet traitée rattachée à 1 ressource S-14 et 1 position S-25), ADR §13.9, discovery-gap-pipeline.md §3.

### User Goal
**Sélectionner la bonne ressource en 2 min et l'engager en 1 geste vers l'artefact (S-36)** — Horeb sort de la bibliothèque avec : (a) la **matière centralisée** (cours, PDF, docs, images, vidéos, liens, notes — ADR §13.8), et (b) le **geste unique** « Ouvrir l'artefact » qui l'ouvre dans l'artefact de document (S-36, 03.5). Source : scénario 03 Q4 (Hope), Q8 passo 4, ADR §13.8.

> **NON COUVERT (déclaration pont, pas d'implémentation)** : le comportement de la bibliothèque quand un **focus actif** est en cours (variante Focus de Home 01.1) — le corps gelé ne précise pas si consulter la bibliothèque est permis/interdit pendant le focus. **Options proposées au standup** :
> - **A** : la bibliothèque reste **lisible** pendant le focus, mais le CTA « Ouvrir l'artefact » est **désactivé (grisé)** — cohérent avec la variante Focus de 01.1 (CTA désactivé si focus en cours) ; recommandé, ne brise pas le focus.
> - **B** : l'ouverture de la bibliothèque est **bloquée** pendant le focus (la sélection n'est pas actionnable ; message « Reprenez après le focus ») — plus strict, NON COUVERT par le corps gelé.
> - **C** : la bibliothèque est lisible + CTA actif, mais l'engagement « Ouvrir l'artefact » est **reporté dans la file de tâches du focus** — NON COUVERT (aucune file de tâches du focus dans le corpus gelé, ne pas inventer).

## 6. Layout Structure (step 15)

*(PROPOSITION SUGGEST — dérivée de ADR §13.9 + trigger-map §6 + garde AD-14)*

**La bibliothèque est une route push lourde `/library` (écran plein)** qui s'ouvre **au-dessus de la sheet S-40** (la sheet reste en arrière-plan, scroll/filtres préservés — invariant S6.2). La composition est **lue d'abord sélectionnée puis engagée** : les items de la bibliothèque sont groupés par type (cours/PDF/docs/images/vidéos/liens/notes), et le CTA « Ouvrir l'artefact » est **fixe en bas d'écran** (garde AD-14 : CTA fixe, jamais une proposition libre de l'agent dans le chemin court).

```
+-------------------------------------+
|  [sheet S-40 en arrière-plan,       |
|   scroll/filtres préservés]         |  ← invariant S6.2
+-------------------------------------+
|  Bibliothèque de ressources         |  ← header (route push /library)
|  Gap : Normes hydrauliques Bénin   |
|  vs Eurocode                       |
|                                     |
|  ── BLOC 1 · COURS ───────────────  |
|  • Cours hydraulique ciblé (ADR    |
|    §13.9, SourceRef) [sélectionné]  |
|  • Autres cours (BA, RDM, ...)     |
|                                     |
|  ── BLOC 2 · DOCUMENTS ────────────  |
|  • PDF / docs (rattachés au gap)   |
|  • Images / schémas                |
|  • Vidéos                          |
|  • Liens (externes, typés)         |
|  • Notes (personnelles)            |
|                                     |
|  [CTA FIXE] « Ouvrir l'artefact »   |  ← ADR §13.9 — ouvre S-36 (03.5)
|     → artefacts-detail S-36 (03.5)  |     l'artefact de document
+-------------------------------------+
|  (BottomNav 5 tabs S-31 visible    |
|   sur la route push /library)       |
+-------------------------------------+
```

**Note** : Les items (cours/PDF/docs/images/vidéos/liens/notes — ADR §13.8) sont **groupés par type** pour la lisibilité 2 min. Le CTA « Ouvrir l'artefact » est le **seul CTA d'action** (garde AD-14) : il **ouvre l'artefact de document ciblé (S-36, 03.5)** et mène vers l'engagement d'apprentissage (ADR §13.9). Le CTA est **fixe** — jamais une proposition libre de l'agent dans le chemin court. Les liens vers l'arbre sémantique (S-34) et les objectifs (S-35) sont **déclarés (pont) mais NON COUVERT** côté navigation (scope-report §B).

## 7. Page States (AD-13, 5 états canoniques)

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| **Default** | Gap chargé dans la bibliothèque, chemin en cours | Items groupés par type (cours/PDF/docs/images/vidéos/liens/notes) + cours ciblé [sélectionné] + CTA fixe « Ouvrir l'artefact » | Tap CTA → artefacts-detail S-36 (03.5) ; tap retour → sheet S-40 (03.3), scroll préservé S6.2 |
| **Loading** | Ouverture de la bibliothèque (mirror local, AD-7) | Skeleton des 2 blocs (~300 ms max, AD-13), CTA indisponible | — |
| **Empty** | Aucune ressource rattachée au gap (gap trop vague / non synchronisé) | État vide actionnable (AD-13) : « Aucune ressource pour ce gap — retour à la sheet » + CTA « Revenir à la sheet S-40 » | Tap → retour sheet (S-40, 03.3) |
| **Error** | Mirror local corrompu / conflit de sync | Bandeau « données locales — resynchronisation en attente » (AD-7), blocs lus en read-only depuis le mirror, CTA « Ouvrir l'artefact » **désactivé** (pas d'engagement sur des données potentiellement stale) | Tap quand réseau revenu (CTA redevient actif) |
| **Offline** (AD-7) | Réseau coupé, bibliothèque chargée depuis le mirror local | Bandeau fine « hors-ligne » (AD-13, A5) ; les items restent **lisibles** (mirror local) ; CTA « Ouvrir l'artefact » **reste actionnable** (l'ouverture de l'artefact est locale ; la sync de l'engagement est différée, AD-7) | Tap CTA → artefacts-detail S-36 (03.5) |
