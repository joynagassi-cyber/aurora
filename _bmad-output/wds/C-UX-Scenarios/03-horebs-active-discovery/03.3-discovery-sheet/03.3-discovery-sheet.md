## 1. Page Purpose (step 10)

**Wording proposé (09/25) :**
> Horeb ouvre la sheet de découverte du gap « **Normes hydrauliques Bénin vs Eurocode** » (tap depuis le feed S-27, 03.2). La sheet **rend l'écart lisible** : elle présente les 7+ champs typés du gap (ADR §13.8) — titre/question de départ, pourquoi maintenant, résumé factuel, sources classées par type, confirmation/contradiction vs savoir actuel, lien avec les cours suivis, lien avec le domaine professionnel visé, compétences concernées, nouveaux concepts, questions ouvertes, actions recommandées (lire / expérimenter / pratiquer / approfondir / suivre / ignorer), liens vers l'arbre sémantique et les objectifs (S-34/S-35, NON COUVERT côté navigation, §5). Le **CTA « Work on this »** (ADR §13.9) est le geste unique qui **attache le gap à une activité d'apprentissage ou un projet** et l'envoie vers la **bibliothèque de ressources (S-14, 03.4)** — jamais un flux de liens passifs (garde trigger-map §6, trap « veille passive »).

La page fait une seule chose : **rendre l'écart lisible (compréhension) puis le rendre actionnable (engagement) en 1 geste** — c'est le pont entre le feed de découverte (S-27) et la bibliothèque (S-14). Sans cette sheet, le gap reste un titre flou dans le feed ; avec elle, Horeb comprend **pourquoi maintenant** et **ce qui est confirmé/contesté** avant de s'engager.

## 3. Mental State (step 12)

**Contexte de la page** : Horeb a tap l'item « Normes hydrauliques Bénin vs Eurocode » dans le feed (03.2), 23 h, thème Nocturne, Pixel 4a, 3G Bénin. Elle est dans un **état de compréhension** : avant de s'engager sur un effort d'apprentissage, elle veut savoir **pourquoi maintenant** et **ce qui est établi vs projeté** (séparation strictes FACT/TREND/ANALYSIS/SCENARIO/UNCERTAINTY, ADR §13.7).

| Dimension | Contenu |
|---|---|
| **Trigger** (ce qui la pousse) | L'écart flou entre le programme suivi et les compétences réellement utilisées au métier réel (trigger-map §7 signal 11, ADR §13.4) ; elle a tap l'item parce qu'il correspond à son écart ressenti, mais **doit comprendre la substance avant de s'engager** (ADR §13.8 : la sheet est un « objet durable », réutilisable dans l'apprentissage et la planification) |
| **Hope** | Comprendre en 2 min de lecture : pourquoi Aurora recommande cette découverte **maintenant**, ce qu'elle **confirme ou contredit** dans son savoir actuel, et quelle **action** engageable réduit le plus vite l'écart (trigger-map §7 signal 13, ADR §13.5 — différenciation professionnelle au Bénin) |
| **Worry** | Re-tomber dans la veille passive : lire des liens sans jamais traiter le problème (trigger-map §7 signal 4, Peur ② « veille passive », ADR §13, §17) — la sheet doit **proposer une action (CTA fixe « Work on this »)** plutôt que multiplier les références ; et l'écart rester **lisible** (pas un bloc factuel opaque) |
| **Questions** | « Pourquoi maintenant ? » · « Ce que je crois est-il confirmé ou contredit ? » · « Quelle compétence cela concerne-t-il dans le métier réel ? » · « Quelle est la première action engageable (lire / pratiquer / approfondir) ? » |
| **Contrainte UX** | Offline = état premier (AD-7) : la sheet est lue depuis le **mirror local PowerSync** (la `DiscoveryItem` est stockée localement, pas un fetch réseau) ; les champs typés restent lisibles sans réseau. Le CTA « Work on this » reste **actionnable offline** (il attache le gap localement ; la synchronisation de l'engagement est différée, AD-7). |

## 4. Desired Outcome (step 13)

### Business Goal
**Conversion de la compréhension du gap en engagement d'apprentissage mesurable** — la sheet est le point de passage du sous-cycle **Discovery → Knowledge** (trigger-map §5, ADR §13.9) : lire la sheet (compréhension) puis « Work on this » (engagement) crée l'activité d'apprentissage ou projet qui relie le gap au savoir existant et se mesure ensuite (compris / appliqué / ignoré, ADR §13.9). Source : scénario 03 Q7 (Business Success : 1 sheet traitée rattachée à 1 ressource S-14 et 1 position S-25), ADR §13.9, discovery-gap-pipeline.md §3.

### User Goal
**Comprendre l'écart en 2 min et l'actionner en 1 geste vers la bibliothèque (S-14)** — Horeb sort de la sheet avec : (a) la **substance** du gap (problème, sources, impact métier, exercices suggérés — ADR §13.8), et (b) le **geste unique** « Work on this » qui l'attache au cours ciblé dans la bibliothèque (03.4, S-14). Source : scénario 03 Q4 (Hope), Q8 passo 3, ADR §13.8.

## 6. Layout Structure (step 15)

*(PROPOSITION SUGGEST — dérivée de ADR §13.8 + trigger-map §6 + garde AD-14)*

**La sheet est une BottomSheet (léger, invariant S6.2)** qui s'ouvre **au-dessus du feed S-27** (le feed reste en arrière-plan, scroll/filtres préservés — invariant S6.2). La composition est **lue d'abord comprise puis agie** : les 7+ champs typés (ADR §13.8) sont groupés en **3 blocs** (Substance → Qualification → Action), et le CTA « Work on this » est **fixe en bas de sheet** (garde AD-14 : CTA fixe, jamais une proposition libre de l'agent dans le chemin court).

```
+-------------------------------------+
|  [feed S-27 en arrière-plan,       |
|   scroll/filtres préservés]         |  ← invariant S6.2
+-------------------------------------+
|  ⌃  (handle BottomSheet)            |
|  [FACTOR] Normes hydrauliques Bénin |  ← badge type (ADR §13.7)
|  vs Eurocode                         |
|                                     |
|  ── BLOC 1 · SUBSTANCE ───────────  |
|  • Pourquoi maintenant              |
|  • Résumé factuel                   |
|  • Sources (classées par type)      |
|                                     |
|  ── BLOC 2 · QUALIFICATION ───────  |
|  • Confirme / contredit mon savoir  |
|  • Lien cours suivis (BA/RDM/hyd.) |
|  • Lien domaine pro visé (Bé.)     |
|  • Compétences concernées           |
|  • Nouveaux concepts                |
|                                     |
|  ── BLOC 3 · ACTION ──────────────  |
|  • Questions ouvertes                |
|  • Actions recommandées            |
|    (lire / expérimenter / pratiquer |
|     / approfondir / suivre / ignorer)|
|                                     |
|  [CTA FIXE] « Work on this »       |  ← ADR §13.9 — attache le gap
|     → bibliothèque S-14 (03.4)     |     à une activité/projet
+-------------------------------------+
|  (BottomNav 5 tabs S-31 masquée    |
|   par la BottomSheet — elle s'ouvre |
|   au-dessus du tab feed courant)    |
+-------------------------------------+
```

**Note** : Les 7+ champs (ADR §13.8 : titre/question, pourquoi maintenant, résumé factuel, sources classées, confirme/contredit, lien cours, lien domaine pro, compétences, nouveaux concepts, questions ouvertes, actions recommandées, liens arbre/objectifs) sont **groupés en 3 blocs** pour la lisibilité 2 min. Le CTA « Work on this » est le **seul CTA d'action** (garde AD-14) : il **attache le gap à une activité d'apprentissage ou un projet** (ADR §13.9) et mène vers la **bibliothèque S-14 (03.4)**. Le CTA est **fixe** — jamais une proposition libre de l'agent dans le chemin court. Les liens vers l'arbre sémantique (S-34) et les objectifs (S-35) sont **déclarés (pont) mais NON COUVERT** côté navigation (scope-report §B).

## 7. Page States (AD-13, 5 états canoniques)

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| **Default** | Item du feed S-27 chargé dans le mirror local, chemin en cours | 3 blocs de champs typés (ADR §13.8) + badge type (FACT/TREND/…) + CTA fixe « Work on this » | Tap CTA → bibliothèque S-14 (03.4) ; tap handle ou swipes-down → fermer (retour feed, scroll préservé S6.2) |
| **Loading** | Ouverture de la sheet (mirror local, AD-7) | Skeleton des 3 blocs (~300 ms max, AD-13), CTA indisponible | — |
| **Empty** | Item non trouvé (id invalide / supprimé / non synchronisé) | État vide actionnable (AD-13) : « Item introuvable — retour au feed » + CTA « Revenir au feed S-27 » | Tap → retour feed (S-27, 03.2) |
| **Error** | Mirror local corrompu / conflit de sync | Bandeau « données locales — resynchronisation en attente » (AD-7), blocs lus en read-only depuis le mirror, CTA « Work on this » **désactivé** (pas d'engagement sur des données potentiellement stale) | Tap quand réseau revenu (CTA redevient actif) |
| **Offline** (AD-7) | Réseau coupé, sheet chargée depuis le mirror local | Bandeau fine « hors-ligne » (AD-13, A5) ; les 3 blocs de champs restent **lisibles** (mirror local) ; CTA « Work on this » **reste actionnable** (l'attache du gap est locale ; la sync de l'engagement est différée, AD-7) | Tap CTA → bibliothèque S-14 (03.4) |
