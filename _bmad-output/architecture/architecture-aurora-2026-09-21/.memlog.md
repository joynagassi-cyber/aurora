- (decision) Paradigm: composite frozen in v1.7 = Modular Monolith + Vertical Slices + Hexagonal (Ports & Adapters) + Local-First + targeted Event-Driven + central Agent Kernel. [ADOPTED]
- (decision) AD: no microservices in V1 — modular boundaries in code only; extraction only on measurable need. [ADOPTED]
- (decision) AD: platform strategy — Phase 1 mobile-only (Ionic React + Capacitor, Android); Electron desktop Phase 2 after mobile production stable. 'Mobile Only for delivery, Platform-Agnostic for the core.' [ADOPTED]
- (decision) AD: domain/application never depend on a vendor, framework, or concrete model name; all external providers behind typed Ports/Providers; optional capabilities must degrade gracefully when absent.
- (decision) AD: module boundaries — a business module never touches another module's internal tables; explicit contracts only. Vertical slices own their scope, tests and contracts.
- (decision) AD: no model key or secret in mobile or web — all AI calls go through server-side Gateway/Router; mobile sees a normalized AIProvider contract only.
- (decision) AD: multi-provider AI: Agent Kernel → Context Builder → Task Classifier → AI Router → AI Policy/Budget → Cloudflare AI Gateway → Provider Adapter. Agnes primary; Workers AI second pool; Groq/Cerebras optional; fallback = dedicated Cloudflare Worker calling Workers AI directly (no business logic in the Worker). [ADOPTED]
- (decision) AD: fallback rules — retry on transient failure, fallback on unavailability/incompatibility/limit; a 429 is never bypassed by rotating keys/accounts; fallback responses stay traceable (provider, model, attempt, reason); free tiers are opportunistic, not SLA, and the registry can auto-retire them.
- (decision) AD: data — PostgreSQL transactional source of truth + pgvector for semantic retrieval; Semantic Tree = knowledge hierarchy (truth lives in Knowledge Base, never in the rendering engine); Event History kept for progression/audit without full Event Sourcing (excluded V1).
- (decision) AD: local-first — PowerSync + SQLite on device, sync to Supabase; the UI always reads local state first.
- (decision) AD: async jobs — everything long/heavy (OCR, transcription, artifact generation, search) is a persisted, idempotent, retryable, observable Job; Supabase Cron → Aurora dispatcher → persisted jobs → Edge Functions/Workers. Never blocks the UI.
- (decision) AD: events are targeted decoupling only — a simple transactional operation stays a direct command; named event list (TaskCompleted, CourseImported, FlashcardReviewed, ProgressEvidenceCreated, SkillStateChanged, GoalUpdated, ArtifactGenerated, JobCompleted, DiscoveryItemCreated).
- (decision) AD: visualization stack frozen — @xyflow/react + @dagrejs/dagre (Semantic Tree), @antv/infographic (explanations), @antv/g2 (data), KaTeX (LaTeX), motion (animation); all behind internal renderer contracts (SemanticTreeRenderer, InfographicRenderer, DataVisualizationRenderer, MathRenderer, AnimationController) so domain never imports engine details. [ADOPTED]
